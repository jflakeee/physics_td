# 목적별 맵 4개 + 종합 스테이지 — UX 구상 검토

> 작성일: 2026-11-08 · 선행 문서: [4갈래 엔딩 UX·스토리](ENDINGS_UX_STORY_REVIEW.md), [배치 없는 UI](NO_PLACEMENT_UI_BRAINSTORM.md)
> 구성: 게임 시작 전 **목적이 다른 맵 4개**(방어·개척·공존·이주활용) 중 하나를 고른다. **5번째 맵**은 네 방식이 모두 가능하고, 플레이 중 선택에 따라 엔딩이 갈리는 **종합 스테이지**다.

---

## 1. 전체 흐름

```
타이틀 → 유역 지도(맵 선택) → 브리핑 → 플레이 → 결과 → 유역 지도
              │
              ├─ 북: 둑마을        (방어)       ┐
              ├─ 동: 채석 계곡     (개척)       │ 목적 맵 — 처음부터 선택 가능
              ├─ 남: 버드나무 들   (공존)       │ 각자 한 가지 방식을 깊게
              ├─ 서: 고원 저수지   (이주·활용)  ┘
              │
              └─ 중앙: 합류점      (종합)  ← 목적 맵 2곳 클리어 시 해금
                                          플레이 중 선택으로 4엔딩 분기
```

**설계 의도**
- 목적 맵 = 각 방식의 **규칙과 손맛을 배우는 곳**. 맵 고르기 자체가 "어떤 방식을 해볼까"라는 선택이므로, 어느 맵을 골라도 점수 상한은 같다.
- 종합 스테이지 = 배운 방식을 **섞어서 스스로 길을 고르는 곳**. 여기서 엔딩이 갈린다.
- 게임의 4방향 홍수 테마를 맵 선택 화면에도 그대로 쓴다: 동서남북 4개 목적 맵, 물이 모이는 **중앙 합류점**이 종합 스테이지.

## 2. 유역 지도 (맵 선택 화면)

### 2.1 레이아웃 (세로 화면 기준)
```
┌─────────────────────────────┐
│ 유역 지도         ⭐ 7/15  📖 1/4 │  별 합계 · 엔딩 도감
├─────────────────────────────┤
│           ┌──────┐           │
│           │ 🛡 북 │           │
│           │둑마을 │ ⭐⭐☆      │
│           └──┬───┘           │
│  ┌──────┐  ┌─┴──┐  ┌──────┐   │
│  │💧 서 │──│ 🔒 │──│⛏ 동 │   │  중앙 = 합류점
│  │고원  │  │합류점│  │채석  │   │  잠금 시 "2곳 클리어 시 열림 (1/2)"
│  └──────┘  └─┬──┘  └──────┘   │
│           ┌──┴───┐           │
│           │🌿 남 │           │
│           │버드나무│ ☆☆☆      │
│           └──────┘           │
├─────────────────────────────┤
│ [선택한 맵 카드 — 아래에서 올라옴]  │
└─────────────────────────────┘
```
- 맵 노드는 최소 88px 정사각형. 탭하면 하단에 **맵 카드**가 올라온다(바로 시작하지 않음 → 오탭 방지).
- 강줄기 그림이 네 맵에서 중앙으로 흘러든다. 목적 맵을 클리어할 때마다 해당 강줄기에 그 방식의 결과가 그려진다(제방 선 / 깎인 산 / 습지 / 저수지) → 지도 자체가 진행도.

### 2.2 맵 카드
```
┌─────────────────────────────┐
│ 🌿 버드나무 들 · 공존            │
│ "강에게 자리를 내주고도 마을을    │
│  지킬 수 있을까?"                │
│                             │
│ 목표  계획 외 침수 0, 생태 70% ↑  │
│ 배울 것  범람원 수문 · 습지 복원   │
│ 조언자  습지 연구원               │
│ 난이도  ●●○   예상 6분           │
│ 최고점  —      ⭐ ☆☆☆            │
│                             │
│        [ 브리핑 보기 ▶ ]         │
└─────────────────────────────┘
```
- **목표·배울 것·예상 시간**을 시작 전에 보여준다(짧은 모바일 세션 판단용).
- 처음 실행 시 북쪽(방어)에 "처음이라면 여기부터" 배지. 강제는 아님.

### 2.3 합류점 해금 조건 — 비교
| 안 | 조건 | 장점 | 단점 |
|---|---|---|---|
| A | 4곳 모두 클리어 | 모든 방식 학습 보장 | 한 방식이 취향에 안 맞으면 막힘 |
| **B** | **2곳 클리어** | 진입 장벽 낮음, 맵 선택이 진짜 선택이 됨 | 일부 방식은 종합 스테이지에서 처음 접함 |
| C | 처음부터 열림 | 자유 | 규칙을 모르고 들어가 좌절 |

**권장 B.** 처음 해보는 방식은 종합 스테이지에서 조언자가 첫 사용 시 짧게 안내(3.4). 4곳을 모두 깨면 보상(4.3)으로 동기 부여.

## 3. 목적 맵 4개 설계

공통: 같은 조작 체계(섹터·거점 탭, 수문 토글, 물 스킬), 5웨이브, 5~7분, 별 3개.

### 3.1 맵별 명세

| | 🛡 북 · 둑마을 | ⛏ 동 · 채석 계곡 | 🌿 남 · 버드나무 들 | 💧 서 · 고원 저수지 |
|---|---|---|---|---|
| 목적 | 방어 | 개척 | 공존 | 이주·활용 |
| 지형 | 평야, 4방향 유입 | 숲·언덕이 기지를 둘러쌈, 자금 적음 | 저지대 농지·습지, 유입량 최대 | 기지가 저지대, 서쪽 고지대 이전 후보지, 빈 저류지 |
| 사용 가능 행동 | 제방 강화, 펌프 | + 벌채, 산 절개, 직강화 | + 범람원 수문, 습지 복원 | + 저류지 수문, 기지 이전, 수차 |
| 설계 장치 | 기본 규칙 학습용 | 자금만으로는 부족 → 자연 자원을 써야 막힘 | 범람원을 열지 않으면 막을 수 없는 유입량 | W3 이후 저지대 방어가 불가능해지는 수위 → 이전 타이밍이 핵심 |
| 클리어 조건 | 기지 HP > 0 | 기지 HP > 0 | 기지 HP > 0 **그리고** 지정 외 구역 침수율 < 20% | 이전 완료 **그리고** 새 기지 HP > 0 |
| ⭐1 | 클리어 | 클리어 | 클리어 | 클리어 |
| ⭐2 | HP 70 이상 | 자재 효율 상위 기준 | 생태 지수 70% 이상 | 저류량 목표 달성 |
| ⭐3 | 시설 N개 이하 | W5 이전 대방벽 완성 | 계획 외 침수 0 | 늦은 이전(W4) + 에너지 목표 |
| 조언자 | 둑지기 노장 | 공병대장 | 습지 연구원 | 수로 기술자 |
| 에필로그 | "선을 지켰다" (얻은 것/잃은 것 카드) | "산이 낮아졌다" | "새가 돌아왔다" | "옛 마을은 물속에" |

- 목적 맵에서 **다른 방식의 행동은 숨긴다**(잠금 아이콘도 표시하지 않음). 화면 요소 수를 줄이는 것이 모바일에서 중요.
- 각 맵은 그 방식이 **필요하도록** 지형·물량을 설계한다. 방어 맵 외에는 "그냥 제방만 쌓기"로는 깰 수 없게 → 방식을 실제로 배운다.

### 3.2 점수 (모든 목적 맵 동일 상한)
```
맵 점수 = 클리어 1000 + 방식 숙련(0~500) + 공통(피해·시간·노 리트라이, 0~200)
```
- 어떤 맵을 골라도 최대 1700. 별은 숙련 가산점 구간과 연동.

### 3.3 목적 맵이 종합 스테이지에 주는 것 — 조언자 합류
클리어한 맵의 조언자가 합류점에 **동행**한다.

| 합류한 조언자 | 종합 스테이지 효과 |
|---|---|
| 둑지기 | 강화 제방 (내구도 +30%) |
| 공병대장 | 벌채·절개 속도 2배 |
| 습지 연구원 | 범람원 흡수량 +30% |
| 수로 기술자 | 수차 해금 (저류 → 자금) |

- **동행하지 않은 조언자의 방식도 기본 행동은 모두 쓸 수 있다.** 동행은 강화일 뿐, 길을 막지 않는다(엔딩 루트 잠금 금지).

### 3.4 처음 쓰는 방식 안내
2곳만 깨고 들어온 플레이어를 위해, 종합 스테이지에서 처음 쓰는 행동에는 해당 조언자가 1회 말풍선 안내(3초, 탭으로 닫기).

## 4. 종합 스테이지 · 합류점

### 4.1 맵 구성
네 목적 맵의 지형 요소를 한 맵에 배치. 방향별로 성격이 다르다.
```
            북: 평야 (제방 유리)
               ║
 서: 고지대 ═══╬═══ 동: 숲·언덕
 + 빈 저류지   [기지]   (자재 자원)
               ║
            남: 저지대 농지 (범람원 후보)
```
- 물은 4방향 동시 유입, 웨이브마다 **주 유입 방향이 바뀜**(예고 화살표).
- 어떤 방향을 어떤 방식으로 막느냐가 곧 루트 선택. 한 방식으로 4방향을 모두 막는 것은 비효율적이도록 설계 → 자연스럽게 섞되, **어느 쪽에 무게를 두는지**로 엔딩이 갈린다.

### 4.2 진행 구조 (3막 + 갈림길)
| 단계 | 웨이브 | 내용 | UX |
|---|---|---|---|
| 1막 | W1~W2 | 모든 행동 개방, 동행 조언자 인사 | 나침반 처음 등장, 짧은 설명 |
| 갈림길 1 | W2 후 | 상류 저수지 위기 카드 | 4지선다 카드(축 아이콘 + 이득/대가 숫자) |
| 2막 | W3~W4 | 선택 결과가 맵에 반영 | 나침반 바늘 이동 애니메이션 |
| 갈림길 2 | W4 후 | 기지 이전 제안 / 마지막 대비 | 이 시점에 **예상 엔딩 카드** 자동 표시 |
| 3막 | W5 | 대홍수 | 선택한 방식이 연출로 드러남 |
| 엔딩 | — | 4엔딩 중 하나 + 에필로그 2장 | 결과 화면 |

### 4.3 엔딩 판정·점수
판정·점수 규칙은 [4갈래 엔딩 문서](ENDINGS_UX_STORY_REVIEW.md) 3장을 그대로 따른다.
- 점수 = 클리어 1000 + 루트 숙련(0~500) + 공통(0~200) + 첫 달성 엔딩 +100
- 추가: 목적 맵 4곳을 모두 클리어했다면 **"네 목소리" 보너스 +100** (모든 조언자 동행).

### 4.4 종합 스테이지 전용 HUD
```
┌─────────────────────────────┐
│ ❤ 80  💰 120  🌊 3/5   🧭   ⏸ │  🧭 = 성향 나침반 (탭 → 예상 엔딩)
│ 동행: 🛡⛏🌿                    │  합류한 조언자 아이콘
├─────────────────────────────┤
│           (맵)                │
├─────────────────────────────┤
│ [섹터를 탭하면 그 자리에서 가능한 │  상황형 액션 바:
│  행동만 2~4개 표시]   [▶ 시작]   │  숲 탭 → 벌채/보존, 들판 탭 → 범람원/제방
└─────────────────────────────┘
```
- 행동이 네 방식 전부라 많아지므로, **탭한 지형에 맞는 행동만** 보여주는 상황형 액션 바로 화면 복잡도를 목적 맵 수준으로 유지.

### 4.5 반복 플레이
- 엔딩 도감 4칸이 채워질 때까지 재도전 유도. 결과 화면의 "다른 길로" 버튼은 아직 못 본 엔딩의 조건 힌트와 함께 재시작.
- 재도전 시 갈림길 카드 **이벤트 순서·주 유입 방향을 시드로 변형**해 같은 판의 반복감을 줄임.

## 5. 목적 맵과 종합 스테이지의 관계 정리

| | 목적 맵 (북·동·남·서) | 종합 스테이지 (합류점) |
|---|---|---|
| 선택 시점 | **게임 시작 전** — 맵을 고르는 것 | **게임 중** — 행동과 갈림길 카드 |
| 행동 범위 | 해당 방식만 | 네 방식 전부 |
| 결과 | 그 방식의 클리어 + 에필로그 | 4엔딩 중 하나 |
| 점수 상한 | 1700 (모두 동일) | 1800 (첫 엔딩 +100), 전 맵 클리어 시 +100 |
| 역할 | 학습·숙련, 조언자 영입 | 종합 판단, 엔딩 수집 |
| 세션 | 5~7분 | 8~10분 |

캠페인 총점 = 맵별 최고점 합. 유역 지도 상단에 ⭐ 합계(최대 15)와 📖 엔딩 도감(4칸) 표시.

## 7. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 목적 맵이 "튜토리얼"처럼 가볍게 느껴짐 | ⭐3 조건을 충분히 어렵게, 맵마다 고유한 지형 퍼즐 |
| 특정 목적 맵만 쉬워 모두 그 맵부터 감 | 맵별 클리어율 측정, 난이도 표시를 정직하게 |
| 종합 스테이지 행동 과다로 모바일 화면 복잡 | 상황형 액션 바, 목적 맵에서 익힌 아이콘 그대로 사용 |
| 조언자 동행 효과가 특정 엔딩을 사실상 강제 | 동행 효과는 +30% 수준으로 제한, 미동행 루트도 클리어 가능한지 봇으로 검증 |
| 4방향 = 4목적 매핑이 오히려 혼동(맵 방향 vs 물 유입 방향) | 유역 지도에서는 방향 대신 **맵 이름·아이콘**을 크게, 방향은 장식으로만 |

## 8. 검증 계획
| 항목 | 합격 기준 |
|---|---|
| 맵 선택까지 걸린 시간(첫 실행) | 중앙값 < 20초 |
| 목적 맵별 첫 클리어율 | 맵 간 차이 15%p 이내 |
| 합류점 해금 후 진입률 | ≥ 70% |
| 합류점에서 나온 엔딩 분포(초회) | 어느 엔딩도 50% 초과하지 않음 |
| 미동행 조언자 루트로 클리어 가능 | 봇 4종 × 동행 조합 전부 클리어 |

## 9. 결정 필요 사항
1. 합류점 해금 조건: **2곳 클리어(권장)** / 4곳 / 처음부터
2. 목적 맵의 방향 배치(현재: 북=방어, 동=개척, 남=공존, 서=이주활용)와 맵 이름
