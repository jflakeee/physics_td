# 공통·특수 스킬 + 경험치 레벨업 교차 스킬 — UX 검토

> 작성일: 2026-11-08 · 선행: [캐릭터 × 맵 스타일](CHARACTER_MAP_UX_REVIEW.md) (이 문서가 그 문서의 3장 스킬, 6장 성장을 대체)
> 요구사항
> 1. 캐릭터 4명은 각자 **공통 스킬**과 **특수 스킬**을 가진다.
> 2. **점수를 얻을 때마다 경험치**가 쌓이고, **레벨업할 때마다 다른 캐릭터의 스킬**을 골라 얻을 수 있다.

---

## 1. 핵심 판단: 레벨은 "판 안"에서 오른다

| 안 | 레벨 유지 범위 | 장점 | 단점 |
|---|---|---|---|
| **A 판 안 레벨 (권장)** | 스테이지 시작 시 Lv1, 판 안에서 성장 | 매 판 다른 빌드 → 리플레이성, "점수 = 경험치"가 즉시 체감, 밸런스가 판 단위로 닫힘 | 판마다 처음부터 |
| B 영구 레벨 | 캐릭터 레벨이 계속 누적 | 장기 성장감 | 고레벨이면 모든 스킬 보유 → 캐릭터 구분 소멸, 신규·기존 유저 밸런스 분리 |
| A+ 혼합 | 판 안 레벨 + 얇은 영구 "숙련" | 둘의 장점 | 시스템 2개 |

**권장 A+.** 판 안 레벨업으로 교차 스킬을 고르고(핵심 재미), 영구 진행은 **카드 풀 해금·코스메틱·도감**만 담당(능력치 누적 없음). 참고 구조(일반 지식): Hades의 여러 신에게 받는 은총(Boon)과 듀오 은총, Vampire Survivors·Brotato의 레벨업 3지선다, Slay the Spire의 카드 보상 + 건너뛰기.

## 2. 스킬 체계

### 2.1 공통 스킬 (4명 모두 보유, 동일 성능)
| 스킬 | 입력 | 효과 | 쿨다운 |
|---|---|---|---|
| 💧 **펌프 가동** | 펌프 거점 탭 (켜기/끄기) | 주변 물 배수, 가동 중 자금 소모 | 없음(토글) |
| 🧊 **긴급 결빙** | 넓은 범위 탭 | 5초간 물 정지 | 긴 쿨다운 |

- 공통 스킬은 **누가 해도 최소한 버틸 수 있는 바닥**. 처음 하는 캐릭터·도전 상성에서도 클리어 가능성을 보장.

### 2.2 특수 스킬 (캐릭터당 4개)
| | 🛡 둑지기 | ⛏ 공병대장 | 🌿 습지 연구원 | 💧 수로 기술자 |
|---|---|---|---|---|
| 패시브 | 제방 내구도 +30% | 자연 자원 채취 시 자재 +50% | 습지·숲이 물 흡수 | 저류된 물 → 자금 |
| 기본기 | 제방 쌓기 | 벌채 | 범람원 개방 | 수문 조작 |
| 전술기 | 모래주머니 벽 | 산 절개 | 습지 복원 | 물길 돌리기 |
| 궁극기 | 철야 보강 | 직강화 | 강의 숨 | 기지 이전 |

### 2.3 시작 구성과 슬롯
```
시작(Lv1): 공통 2 + 자기 패시브 + 자기 기본기
레벨업으로 채우는 슬롯: 액티브 최대 4칸 (자기 전술기·궁극기 또는 다른 캐릭터 스킬)
패시브: 최대 3개 (자기 1 + 교차 2)
```

### 2.4 교차 스킬 규칙
| 규칙 | 이유 |
|---|---|
| 다른 캐릭터의 **패시브·기본기·전술기**는 얻을 수 있다 | 빌드 다양성 |
| 다른 캐릭터의 **궁극기는 얻을 수 없다** | 캐릭터 정체성 유지 (기지 이전 같은 큰 결정은 수로 기술자의 것) |
| 교차 액티브는 최대 **2칸** | 4칸 중 최소 절반은 자기 스킬 → "누구로 플레이했는가"가 남음 |
| 교차 스킬은 원래 성능의 100%, 대신 **강화 단계는 1단계까지** | 빌려온 스킬은 넓게, 자기 스킬은 깊게 |

## 3. 경험치 — 점수를 얻을 때마다

### 3.1 점수 = 경험치 (1:1)
판 중 점수가 발생하는 모든 순간에 같은 양의 경험치가 쌓인다. **네 방식 모두 비슷한 속도로 점수를 벌 수 있게** 점수원을 나눈다.

| 점수원 | 예 | 주로 버는 방식 |
|---|---|---|
| 배수량 | 펌프·배출구로 뺀 물 1단위당 +1 | 공통 |
| 무피해 시간 | 기지 피해 없는 10틱마다 +5 | 방어 |
| 차단 효율 | 제방이 막아낸 유입량 | 방어·개척 |
| 자재 확보 | 벌채·절개로 얻은 자재 | 개척 |
| 생태 회복 | 습지·숲 지수 상승 | 공존 |
| 저류·생산 | 저장한 물, 수차 에너지 | 활용 |
| 웨이브 클리어 | +100 | 공통 |

### 3.2 레벨 곡선
- 목표: 5웨이브 한 판에 **레벨업 5~6회** (W1에 1회, 이후 웨이브당 1회 + 보너스 1회).
- 필요 경험치: `100 × 1.35^(lv−1)` 기준, 맵별 점수량에 맞춰 조정.
- 점수가 높은 플레이 = 더 많은 레벨업 = 더 강해짐 → 잘하는 플레이어가 빌드를 더 넓게 경험.

### 3.3 레벨업 시점 — 모바일 기준
| 안 | 동작 | 판단 |
|---|---|---|
| 즉시 정지 | 경험치 바가 차는 순간 화면 정지 → 카드 선택 | 물 흐름이 핵심인 게임에서 위기 순간 흐름이 자꾸 끊김 |
| **웨이브 끝 정산 (권장)** | 웨이브 중엔 "레벨업 대기 ●●" 배지만, 웨이브가 끝나면 쌓인 레벨업을 연속 선택 | 준비 단계와 합쳐져 생각할 시간 충분, 한 손 플레이 방해 없음 |
| 선택적 즉시 | 대기 배지를 탭하면 일시정지하고 바로 선택 | 권장안에 **옵션으로 추가** — 위기 탈출용 |

## 4. 레벨업 카드 UX

### 4.1 화면
```
┌─────────────────────────────┐
│        LEVEL 3 ▸ 4    (남은 선택 2)  │
├─────────────────────────────┤
│ ┌─────────────────────────┐ │
│ │ 🛡 [자기] 모래주머니 벽       │ │  자기 스킬: 테두리 = 캐릭터 색
│ │ 스와이프 방향에 임시벽 6초     │ │
│ │ 🛡 수호 +                   │ │  성향 축 아이콘
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ 🌿 [교차] 범람원 개방         │ │  교차 스킬: 원 소유 캐릭터 얼굴
│ │ 들판 수문 탭 → 물을 들판으로   │ │
│ │ 🌿 공존 +   ✨ 융합 가능: 1    │ │  보유 스킬과 융합 조합이 있으면 표시
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ 💧 [교차] 저류 → 자금 (패시브) │ │
│ └─────────────────────────┘ │
│  [ 건너뛰기: 자금 +40 ]   [🎲 1]   │  건너뛰기도 보상, 다시 뽑기 1회
└─────────────────────────────┘
```
- 카드 3장 세로 배치(엄지로 누르기 쉬운 전체 너비 카드).
- 구성: **자기 스킬/강화 1장 + 교차 스킬 2장**이 기본. 맵 스타일에 맞는 교차 스킬이 약간 더 잘 나옴(범람원 맵이면 🌿 가중).
- 카드를 길게 누르면 효과 미리보기(맵 위에 적용 범위 표시).
- 슬롯이 꽉 찼을 때 액티브를 고르면 **교체할 스킬 선택** 단계로.

### 4.2 "어떤 선택이든 가산점"
| 선택 | 판 종료 시 가산점 |
|---|---|
| 자기 스킬만 선택 → **순수 빌드** | "장인" 보너스: 자기 스킬 강화 단계 합 × α |
| 교차 스킬 2칸 이상 → **혼합 빌드** | "융합" 보너스: 서로 다른 캐릭터 수 × β + 발동한 융합 효과 수 × γ |
| 건너뛰기 | 즉시 자금 + 판 종료 시 "절제" 보너스(건너뛴 횟수 × δ) |

- α·β·γ·δ는 **순수·혼합·절제 빌드의 기대 최고 가산점이 같도록** 봇 시뮬레이션으로 맞춘다(±5%).
- 결과 화면에 빌드 유형과 보너스 이름을 표시.

## 5. 융합 효과 (Hades 듀오 은총형)

두 캐릭터의 특정 스킬을 함께 가지면 자동으로 발동하는 추가 효과. **발견하는 재미 + 도감 수집.**

| 조합 | 융합 효과 |
|---|---|
| 🛡 제방 쌓기 + 🌿 습지 복원 | **녹색 제방**: 제방 뒤쪽이 습지가 되어 새는 물을 흡수 |
| ⛏ 벌채 + 🌿 습지 복원 | **통나무 둑**: 벤 나무로 비버 댐 같은 낮은 둑 → 생태 감소 상쇄 |
| ⛏ 산 절개 + 💧 수문 조작 | **계곡 저수지**: 깎은 자리가 저류지가 됨 |
| 🛡 모래주머니 벽 + 💧 물길 돌리기 | **유도벽**: 임시벽이 물을 지정 방향으로 흘려 보냄 |
| 🌿 범람원 개방 + 💧 저류 → 자금 | **논 관개**: 범람원 물이 수입이 됨 |
| 🛡 패시브 + ⛏ 패시브 | **석축**: 제방 내구도 추가 +20% |

- 레벨업 카드에 "✨ 융합 가능" 표시 → 조합을 노리는 선택 유도.
- 처음 발동 시 짧은 연출 + 도감 등록.

## 6. 엔딩·성향과의 연결
- 판 중 **사용한 스킬의 성향 축**(🛡⛏🌿💧)이 누적되어 나침반에 표시된다.
- 에필로그는 `플레이한 캐릭터 × 가장 많이 쓴 교차 성향`으로 결정 → 예: "둑지기 + 공존 성향" = "녹색 제방의 마을".
- 순수 빌드면 캐릭터 고유 엔딩. 즉 **레벨업 선택이 곧 엔딩 선택**이 되어, 이전 문서의 "게임 중 선택으로 갈리는 엔딩"이 별도 종합 스테이지 없이 모든 맵에서 자연스럽게 구현된다.

## 8. 영구 진행 (얇게)

| 요소 | 내용 | 능력치 영향 |
|---|---|---|
| 캐릭터 숙련도 | 그 캐릭터로 누적한 점수 | 없음 |
| 카드 풀 해금 | 숙련도 단계마다 그 캐릭터의 **스킬 변형 카드**가 모든 캐릭터의 레벨업 풀에 추가 (예: 모래주머니 벽·두꺼운형) | 선택지 다양성만 |
| 융합 도감 | 발견한 융합 효과 | 없음 |
| 엔딩 도감 | 캐릭터 × 성향 에필로그 | 없음 |
| 코스메틱 | 캐릭터 의상, 제방·물 색 테마 | 없음 |

→ 신규·기존 유저가 같은 판에서 같은 조건. 점수 공정성 유지.

## 10. 결정 필요 사항
1. 레벨 범위: **판 안 레벨 + 얇은 영구 진행(권장)** / 영구 레벨
2. 레벨업 시점: **웨이브 끝 정산 + 선택적 즉시(권장)** / 즉시 정지
3. 다른 캐릭터의 궁극기 획득 금지 유지 여부
4. 교차 액티브 슬롯 상한(현재 2칸)
5. 첫 구현 범위 — 권장: 캐릭터 2명(둑지기·습지 연구원), 공통 2 + 특수 4씩, 융합 효과 1개(녹색 제방), 웨이브 끝 레벨업 카드
