# P1-A: 지형 고도 기반 물 흐름 (초기 구현)

## 배포 경로 구분
- 메인 사이트 `/`: TypeScript v2 게임 (`src/main.ts`) — 이번 변경 **적용 대상 아님**.
- `/legacy/`: 탑뷰 자연재해 프로토타입 (`topview-engine.js`, `src.js`) — 이번 변경 **적용 대상**.
- `/v3/`, `/v4/`: 별도 실험 버전. 이번 변경 없음.

## 변경사항
- 40×24 탑뷰에 고도 함수 `terrainHeight(x,y)` 추가.
- 중앙 기지로 향하는 십자형 저지대와 주변의 완만한 고지대를 생성.
- 기존 수위 차만 계산하던 확산에 지면 고도를 더한 수두(`지면 고도 + 물 깊이`) 차이를 적용.
- 탑뷰 화면에 고지대를 반투명 갈색으로 표현.
- 지형의 대칭성과 고지대에서 낮은 지대로 이동하는 현상에 대한 자동 테스트 추가.

## 물리적 한계
- 이 모델은 실제 유체역학 계산이 아닌 게임용 단순 격자 확산이다.
- 고도는 현재 고정이며 플레이어가 땅을 파거나 쌓을 수 없다.
- 셀마다 흐름을 순차 처리하는 방식은 회전 방향에 따른 편향이 생길 수 있다.
- 사방 홍수가 실제 기지까지 도달해 적절한 난이도를 형성하는지는 별도 시뮬레이션·실기 검증이 필요하다.
- 이번 단계는 수두 기반 흐름의 **첫 단계**이며 제방 내구도, 수로 굴착, 고도 편집은 아직 구현하지 않았다.

## 후속 P1
1. 지형을 편집하는 수로 파기/성토 기능 및 자원 비용.
2. 물 이동량의 보존과 방향 편향을 검증하는 테스트.
3. 기지 도달 시간·침수율 기반 웨이브 밸런스.
4. 메인 v2와 탑뷰 프로토타입의 게임 엔진 통합 여부 결정.

## 검증
- `npm test`, `npm run build`, `node --check src.js`를 CI에서 확인.
- Pages 배포와 실제 브라우저 동작은 각각 따로 확인.
