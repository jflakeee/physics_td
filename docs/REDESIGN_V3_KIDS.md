## 0. 결론

1. **v2의 물리 시뮬레이션은 유지하고 그 위의 규칙과 화면을 갈아엎는다.** 복잡함은 물에서 오지 않는다. 물 위에 얹은 자금, 레벨 게이지, 구역 선, 펌프 거점, 성향 축, 융합, 슬롯 규칙이 복잡함을 만든다.
2. **물은 위에서만 내려오고 마을은 아래에 있다(1방향).** 마을 앞에는 처음부터 **울타리 방어막**이 있고, 이 방어막이 곧 체력이다.
3. **조작은 버튼 3개다.** 캐릭터 기술 2개와 필살기 1개만 쓴다. 자금이 없고 쿨다운만 있다.
4. **모든 기술은 "물은 사라지지 않는다"를 지킨다.** 물을 막거나, 돌리거나, 담거나, 상태를 바꾸거나(얼음·수증기), 밖으로 퍼낸다. 판타지·SF는 이 다섯 가지를 *어떻게* 하는지에 대한 겉포장이다.
5. **바로 갈아엎지 않고 1맵 프로토타입으로 아이 플레이테스트부터 한다**(§11).

- 아이콘(🛍 모래주머니, 🌙 철야 보강)이 무엇을 하는지 그림만 보고 알기 어렵다.

### 2.2 어린이 UI 지침

- 터치 대상: 어린이는 성인(약 1 cm)보다 훨씬 커야 한다. 자료마다 **2 cm 이상**, **60–80 pt**를 권한다. 간격도 넉넉하게 둔다.
- 한 화면의 선택지 수를 줄인다. 연령대 자료에 "선택지를 줄여 압도되지 않게"라는 정성적 권고만 있고, 정해진 숫자는 찾지 못했다.
- 7–10세는 읽기 수준 차이가 크다. 긴 설명은 그림이나 음성으로 대신한다.
- 튜토리얼은 읽게 하지 말고 **해 보게** 한다. 메시지는 놀이를 멈추지 않게 띄운다(PvZ 원칙).

## 3. V3 핵심 규칙

### 3.1 무대: 1방향

```
┌──────────────────────────┐
│ ☁ ☁ ☁   산 / 댐 (물이 나옴) │  ← 물은 여기서만 들어온다. 오기 3초 전에 구름이 반짝인다
│  ↓   ↓    ↓              │
│     골짜기 · 들판 · 숲      │  ← 기술을 쓰는 곳
│                          │
│ ════ 울타리 방어막 ════    │  ← 기본 방어선 (= 체력)
│  🏠 🏠 🏠  마을            │
└──────────────────────────┘
```

- 세로 화면 전용. 격자는 v2와 같은 64×96을 쓰되 기지를 아래쪽 띠로 옮긴다.
- 물이 들어오는 곳은 맵 위쪽 가장자리 1–3곳뿐이다. 웨이브가 진행되면 같은 곳에서 물이 더 많이 나오거나, 들어오는 곳이 하나 늘어난다.

### 3.2 울타리 방어막 (기본 방어)

- 마을 앞을 가로지르는 울타리가 **처음부터** 있다. 플레이어가 지을 필요가 없다.
- 물이 울타리에 닿으면 물 높이에 비례해 울타리가 깎인다. **울타리 막대 = 체력**이다.
- 울타리가 0이 된 칸으로 물이 넘어가면 마을이 젖는다. 마을이 다 잠기면 진다.
- 웨이브 사이에 울타리가 조금 회복된다(아이에게 "숨 돌릴 틈").
- 물리 근거: 수압은 물 깊이에 비례한다(p = ρgh). 그래서 깊이 고인 물일수록 울타리를 빨리 깎는다. "물을 울타리 앞에 고이게 두지 말자"를 아이도 눈으로 배운다.

### 3.3 조작: 버튼 3개

```
┌──────────────────────────┐
│ ❤❤❤❤░  🌊●●○        ⏸   │  ← 울타리 하트 · 남은 웨이브 · 일시정지
├──────────────────────────┤
│                          │
│           맵             │
│                          │
├──────────────────────────┤
│  [🧱 벽]  [⛏ 물길]  [⭐ 필살] │  ← 72px 이상, 그림 + 두 글자
└──────────────────────────┘
```

- **누르고 → 그린다/탭한다.**
  - 선 기술(벽, 물길, 용암): 버튼을 누르고 맵에 손가락으로 선을 긋는다.
  - 점 기술(얼리기, 저수지, 레이저, 미사일): 버튼을 누르고 맵을 탭한다.
- 놓을 수 있는 곳만 밝아진다. 놓을 수 없는 곳은 회색으로 바뀌고 이유를 그림으로 보여 준다.
- 비용은 **쿨다운 하나**뿐이다. 버튼이 시계처럼 차오르면 다시 쓸 수 있다.
- 필살기 게이지는 "막은 물의 양"으로 찬다. 가득 차면 버튼이 빛난다.
- 없애는 것: 💰 자금, 펌프 거점 켜기/끄기, 구역 경계선(조준할 때만 보인다), 레벨 숫자와 EXP 숫자, 배속 버튼(일시정지 메뉴 안으로).

### 3.4 성장

- 웨이브가 끝날 때마다 **큰 카드 2장 중 1장**을 고른다. 카드는 "벽 ★2: 더 길게"처럼 *가진 기술이 세지는 것*만 나온다.
- 희귀도, 성향 축, 융합, 교차 스킬, 슬롯 규칙은 없앤다(아이 모드 기준).
- 맵 하나는 웨이브 3개, 3–4분이다.
- 별: 울타리 하트가 남은 만큼 ★1–3. 별로 다음 맵과 새 캐릭터가 열린다.

## 4. 기술 설계: 물리 법칙 안의 판타지/SF

### 4.1 다섯 가지 동사

물은 만들어지지도 없어지지도 않는다. 기술은 반드시 다음 다섯 가지 중 하나다. 버튼 색도 동사별로 정해서 아이가 "무슨 일을 하는 기술인지" 색으로 안다.

| 동사 | 색 | 물리 | 시뮬 연산 (v2 재사용 / 신규) |
|---|---|---|---|
| **막기** | 갈색 | 지형을 높인다 | `terrain +h` (v2 제방) |
| **돌리기** | 주황 | 지형을 낮춰 물길을 낸다 | `terrain −h` 선 (v2 범람원 개방 확장) |
| **담기** | 파랑 | 우묵한 곳·빈 틈에 물을 저장한다 | 구덩이 `terrain −h` 면 / 모래 흡수 용량 (신규) |
| **바꾸기** | 하늘·빨강 | 상(phase)을 바꾼다: 물 → 얼음 / 물 → 수증기 | v2 얼음 / 증발 (신규: 에너지 한도) |
| **내보내기** | 보라 | 맵 밖으로 옮긴다 | v2 펌프·배수구 |

### 4.2 기술 목록

| 기술 | 동사 | 포장 | 물리 근거 | 시뮬 처리 | 입력 | 쿨다운 기준 |
|---|---|---|---|---|---|---|
| 🧱 방어벽 세우기 | 막기 | 흙벽 | 높은 땅은 물이 못 넘는다. 벽은 수압에 깎인다 | 선 경로 `terrain +h`, 내구도 | 선 | 짧음 |
| ⛏ 물길 파기 | 돌리기 | 삽 / 굴착 드릴 | 물은 낮은 곳으로 흐른다 | 선 경로 `terrain −h` | 선 | 짧음 |
| 🕳 저수지 만들기 | 담기 | 큰 구덩이 | 구덩이 부피만큼만 담긴다. 넘치면 다시 흐른다 | 원형 `terrain −h`, 담긴 양 표시 | 탭 | 보통 |
| 🏖 모래 흡수 | 담기 | 모래주머니 / 마른 모래밭 | 모래는 빈틈(공극률 대략 25–40%)만큼 물을 머금고 가득 차면 더 못 먹는다 | 셀별 흡수 용량, 포화되면 정지 (신규) | 탭 | 보통 |
| 💧 배수 펌프 | 내보내기 | 펌프 로봇 | 펌프는 시간당 정해진 양만 퍼낸다 | v2 펌프 (자금 대신 작동 시간) | 탭 | 보통 |
| 🧊 얼리기 | 바꾸기 | 서리 마법 | 얼음은 흐르지 않고 시간이 지나면 녹는다. 질량은 같다 | v2 결빙 | 탭 | 보통 |
| 🌋 용암 흐르기 | 바꾸기 + 막기 | 화산 정령 | 용암이 물에 닿으면 물은 수증기가 되고 용암은 식어 **바위**가 된다 | 선 경로에 용암 셀(열량), 물과 만나면 증발 + 바위 (신규) | 선 | 김 |
| 🔆 레이저 증발 | 바꾸기 | 태양광 위성 레이저 | 물을 끓여 날리려면 큰 에너지가 든다. 레이저 한 번의 에너지만큼만 증발 | 원형 영역 증발, 1회 에너지 한도 (신규) | 탭 | 김 |
| 🚀 미사일 폭발 | 돌리기 + 담기 | 굴착 미사일 | 폭발은 땅을 파서 크레이터를 만들고 물을 바깥으로 밀어낸다 | 원형 `terrain −h` + 바깥 방향 흐름 충격 (신규) | 탭 | 김 |
| 🚀🕳 미사일 저수지 | 담기 | 필살기 | 큰 크레이터 = 큰 저수지. 크레이터 테두리 흙은 둑이 된다 | 큰 원형 `terrain −h`, 테두리 `+h` | 탭 | 필살 게이지 |

### 4.3 물리로 정한 밸런스

- 물 1 kg을 얼리는 데 빼야 하는 열은 약 334 kJ이고, 끓여 날리는 데 드는 열은 약 2260 kJ로 **약 7배**다.
  → **증발 기술(레이저·용암)은 얼리기보다 쿨다운이 길거나 처리량이 작아야 한다.** 숫자 근거가 있는 밸런스라서 설명하기 좋다.
- 얼음은 질량이 남는다. 녹으면 물이 다시 생긴다. 증발한 물만 진짜로 사라진다(맵 밖 하늘로 나감 = 내보내기와 같은 효과).
- 저수지와 모래는 **용량**이 있다. 가득 차면 넘친다. 무한 흡수를 금지한다.
- 펌프는 퍼낸 물을 맵 밖 강으로 보낸다. 물이 사라지는 것이 아니라 옮겨진다.

### 4.4 조합 (발견하는 재미)

물리에서 자연스럽게 나오는 조합만 넣는다. 설명하지 않고 아이가 발견하게 둔다.

| 조합 | 결과 | 물리 |
|---|---|---|
| 용암 + 물 | 수증기 + **바위 벽** | 용암 냉각 |
| 미사일 크레이터 + 물길 | 물길이 크레이터로 흘러 들어가 저수지가 된다 | 낮은 곳으로 흐름 |
| 얼리기 + 물길 | 얼음 댐으로 물길 입구를 잠깐 막았다가 녹으면 연다 | 상변화, 질량 보존 |
| 모래 + 저수지 | 모래가 먼저 젖고, 넘친 물만 저수지로 | 용량 순서 |
| 레이저 + 얼음 | 얼음이 녹아 물이 된다 (**실수 조합**) | 열 → 융해 |

### 4.5 제외한 아이디어

- 물을 없애는 마법(소멸), 중력 반전, 물을 위로 흐르게 하는 바람: R7 위반이라 넣지 않는다.
- 순간이동 포털(SF 웜홀)은 질량이 보존되므로 **넣을 수 있다**. 다만 1방향 규칙을 흐리므로 확장 후보로만 둔다.

## 5. 캐릭터

캐릭터 하나 = 기술 2개 + 필살기 1개. 한 판에 한 캐릭터만 쓴다.

| 캐릭터 | 세계관 | 기술 1 | 기술 2 | 필살기 | 출시 |
|---|---|---|---|---|---|
| 🛡 둑지기 | 현실 | 🧱 방어벽 세우기 | 🏖 모래 흡수 | 만리 방벽: 울타리 전체를 높이고 회복 | 1차 (튜토리얼) |
| ⛏ 두더지 로봇 | SF | ⛏ 물길 파기 | 🕳 저수지 만들기 | 드릴 대운하: 위에서 맵 끝까지 곧은 수로 | 1차 |
| ❄ 서리 마법사 | 판타지 | 🧊 얼리기 | 🧱 얼음벽 (녹는 벽) | 빙하 시대: 모든 물 표면을 5초 동안 얼림 | 1차 |
| 🌋 화산 정령 | 판타지 | 🌋 용암 흐르기 | 💨 증기 분출 (작은 증발) | 화산 폭발: 큰 바위 산이 솟음 | 2차 |
| 🚀 우주 공병 | SF | 💧 배수 펌프 | 🔆 레이저 증발 | 🚀🕳 미사일 저수지 | 2차 |

- 1차 3명은 동사 "막기·돌리기·담기·바꾸기"를 고르게 나눠 갖는다.
- 2차 2명은 에너지가 큰 기술(증발·폭발)이라 뒤로 미룬다. 신규 시뮬 연산이 필요한 것도 이 둘에 몰려 있다.

## 7. 화면 규칙

- 버튼 72 px 이상, 간격 12 px 이상. 그림 + 두 글자 이름(벽, 물길, 얼음).
- 숫자는 결과 화면에만. 플레이 중에는 하트·물방울·별·막대만 보인다.
- 글: 한 번에 8단어 이하. 쉬운 말을 쓴다: "펌프 가동" → "물 퍼내기", "제방" → "벽".
- 물이 오기 3초 전에 위쪽 구름이 반짝이고 화살표가 내려온다(예고).
- 튜토리얼은 맵 1에서 손가락 그림 하나로만: "여기에 선을 그어 봐".
- 진 화면: "물이 여기로 넘어왔어요" + 화살표 + [다시]. v2 침수 원인 추적기를 쓴다.
- 접근성: 왼손 모드, 글자 120%, 움직임 줄이기는 그대로 가져간다.

## 8. v2에서 가져가는 것 / 버리는 것

| 구분 | 항목 |
|---|---|
| **유지** | 유체 시뮬(2단계 가상 파이프, Float64, 질량 보존), 얼음 융해, 지형 높이, 배수구·펌프 처리량, 결정론 RNG, 체크포인트·저장, 렌더러(물 색조, 주민), 침수 원인 추적기, 봇 밸런스 틀, e2e |
| **수정** | 맵: 기지를 아래 띠로, 유입을 위쪽 가장자리로. 기지 피해 → 울타리 내구도. 스킬 데이터 JSON(동사·입력 방식·쿨다운만). 레벨업 → 2장 강화 카드 |
| **신규** | 울타리 개체, 선 그리기 입력, 모래 흡수 용량, 저수지 담긴 양 표시, (2차) 용암 셀·증발 에너지·폭발 충격 |
| **숨김/제거** | 자금 경제, 펌프 거점 토글, 구역 경계선 상시 표시, 성향 축과 엔딩 분기, 융합, 희귀도, 교차 스킬, 슬롯 규칙, 배속 버튼 |

- 숨김 항목의 코드는 바로 지우지 않는다. 결정(§10) 전까지 v2 모드로 남겨 둘 수 있다.

## 9. 위험과 대응

| 위험 | 대응 |
|---|---|
| 너무 쉬워져 어른이 금방 지루해한다 | 별 3개 조건과 조합 발견, 2차 캐릭터, "장마" 같은 다중 유입 맵으로 깊이를 낸다. Where's My Water?처럼 아이에게는 클리어, 어른에게는 별 3개 |
| 선 긋기 오조작 | 손을 떼기 전까지 미리보기, 손을 뗀 뒤 0.3초 안에 같은 버튼 다시 누르면 취소 |
| 신규 물리(용암, 폭발)의 성능 | 2차로 미룬다. 1차는 v2 연산 재사용 비율이 높다 |
| 판타지·SF 톤이 섞여 산만하다 | 캐릭터 하나당 세계관 하나. 맵은 공통 자연 배경 |
| 결정 수가 줄어 TD의 재미가 줄어든다 | "어디에 그을까"라는 공간 판단은 남는다. 플레이테스트로 확인한다 |

## 10. 결정이 필요한 것

1. **v2를 대체할지, "쉬움 모드"로 같이 둘지**. 권장: 1차 프로토타입 결과를 보고 결정. 결과가 좋으면 V3를 기본으로, v2 규칙은 "고수 모드"로.
2. **1차 캐릭터 3명 구성**(둑지기, 두더지 로봇, 서리 마법사)이 맞는지.
3. **자금 경제를 완전히 없앨지**. 권장: 없앤다(쿨다운만).
4. **세로 화면 고정**을 받아들일지. 권장: 받아들인다.
