# 캐릭터 선택 × 맵 스타일 — UX 검토

> 작성일: 2026-11-08 · 선행 문서: [목적별 맵 + 종합 스테이지](STAGE_SELECT_UX_REVIEW.md), [4갈래 엔딩](ENDINGS_UX_STORY_REVIEW.md), [배치 없는 UI](NO_PLACEMENT_UI_BRAINSTORM.md)
> 변경된 구조: 맵은 **4가지 스타일**로 나뉘고 스타일마다 **여러 장**이 있다. 플레이어는 **스킬 4개를 가진 캐릭터** 4명 중 하나를 골라 맵을 클리어한다.
> ⚠️ 스킬·성장 구조(3장, 6장)는 [공통·특수 스킬 + 레벨업 교차 스킬](SKILL_LEVELUP_UX_REVIEW.md) 문서로 갱신됨.
> 해석: "네 가지 스킬을 가진 캐릭터" = **캐릭터 4명 × 각자 스킬 4개**로 정리했다(하단 스킬 버튼 4칸이 모바일 엄지 영역에 맞음). 다르게 의도했다면 9장에서 조정.

## 1. 구조 요약

```
         캐릭터 4명 (= 해결 방식)           맵 스타일 4종 (스타일당 여러 장)
  🛡 둑지기     (방어)               ┌ 평야형     : 둑마을, 갈대벌, 운하 교차로 …
  ⛏ 공병대장   (개척)    ×         ├ 산림·계곡형 : 채석 계곡, 삼나무 협곡 …
  🌿 습지 연구원 (공존)               ├ 범람원형   : 버드나무 들, 갈대 삼각주 …
  💧 수로 기술자 (이주·활용)          └ 고원·저수지형 : 고원 저수지, 계단식 논 …
```
- 이전 구상의 **"맵 = 방식"** 이 **"캐릭터 = 방식, 맵 = 무대"** 로 바뀐다. 같은 맵을 다른 캐릭터로 다시 풀 수 있어 콘텐츠 재사용성이 크게 오른다(맵 N장 × 캐릭터 4명).
- 어떤 캐릭터 × 어떤 맵 조합이든 **클리어 가능 + 가산점**을 보장한다(4장).

## 3. 캐릭터 4명 × 스킬 4개

### 3.1 스킬 슬롯 규칙 (모든 캐릭터 공통)
| 슬롯 | 종류 | 입력 | 설계 의도 |
|---|---|---|---|
| ① 패시브 | 상시 효과 | 없음 | 캐릭터 정체성 |
| ② 기본기 | 짧은 쿨다운 | **섹터·거점 탭** | 매 웨이브 반복 사용 |
| ③ 전술기 | 중간 쿨다운 | **스와이프/넓은 범위 탭** | 위기 대응 |
| ④ 궁극기 | 게이지 충전 | 버튼 길게 누르기 | 웨이브당 1회 역전 수단 |

모든 스킬은 **좌표 정밀 선택 없이** 쓸 수 있다(섹터·거점·수문·넓은 범위).

### 3.2 캐릭터별 스킬

| | 🛡 둑지기 | ⛏ 공병대장 | 🌿 습지 연구원 | 💧 수로 기술자 |
|---|---|---|---|---|
| 방식 | 방어 | 개척 | 공존 | 이주·활용 |
| ① 패시브 | 제방 내구도 +30% | 벌채·절개 시 자재 +50% | 습지·숲 섹터가 물 흡수 | 저류된 물이 자금으로 전환 |
| ② 기본기 | **제방 쌓기** (섹터 탭) | **벌채** (숲 섹터 탭 → 자재) | **범람원 개방** (들판 수문 탭) | **수문 조작** (저류지 수문 탭) |
| ③ 전술기 | **모래주머니 벽** (스와이프 방향 임시벽) | **산 절개** (언덕 거점 → 고성벽) | **습지 복원** (범위 탭 → 흡수 지대) | **물길 돌리기** (스와이프 방향으로 유량 전환) |
| ④ 궁극기 | **철야 보강** (모든 제방 즉시 수리) | **직강화** (강을 곧게 → 물이 빨리 빠짐) | **강의 숨** (범람원 전체 흡수량 3배, 10초) | **기지 이전** (고지대로 이동, 이후 피해 대폭↓) |
| 대가 | 자금 소모 큼 | 생태 −, 토사·산사태 이벤트 | 외곽 수입 −, 일부 침수 감수 | 이전 중 방어 공백, 저류지 월류 위험 |
| 난이도 | 쉬움 (입문 추천) | 보통 | 보통 | 어려움 |

- 공통 기본 조작(펌프 켜기/끄기 등)은 모두 가능, **방식의 핵심은 스킬로만** 쓸 수 있다 → 캐릭터 선택이 실제로 플레이를 바꾼다.
- 대가는 플레이 중 **게임 효과**로만 존재하고, 점수 감점은 없다(4장).

## 4. 상성과 "모든 조합에 가산점"

### 4.1 맵 스타일 × 캐릭터 상성표
| 맵 스타일 \ 캐릭터 | 🛡 둑지기 | ⛏ 공병대장 | 🌿 습지 연구원 | 💧 수로 기술자 |
|---|---|---|---|---|
| 평야형 | **정석** | 도전 | 보통 | 보통 |
| 산림·계곡형 | 보통 | **정석** | 도전 | 보통 |
| 범람원형 | 도전 | 보통 | **정석** | 보통 |
| 고원·저수지형 | 보통 | 도전 | 보통 | **정석** |

- **정석**: 그 캐릭터가 가장 쉽게 푼다. **도전**: 어렵지만 가능하다(봇 검증 필수).

### 4.2 점수 — 어려운 조합일수록 보정
```
맵 점수 = 클리어 1000
        + 캐릭터 숙련(0~500)        ← 캐릭터마다 기준이 다름 (엔딩 문서 3.3과 동일)
        + 상성 보정 (정석 +0 / 보통 +100 / 도전 +200)
        + 공통(피해·시간·노 리트라이, 0~200)
        + 첫 조합 보너스 +50        ← 이 맵을 이 캐릭터로 처음 클리어
```
- **정석**은 클리어가 쉬워 숙련 점수를 채우기 쉽고, **도전**은 숙련을 덜 채워도 보정으로 만회 → 조합 간 **실제 기대 최고점 차이 ±5%** 를 목표로 튜닝(7장 검증).
- 결과 화면에는 "도전 조합 보너스 +200"처럼 **보너스 이름으로** 표시. "불리한 선택" 같은 표현은 쓰지 않는다.

### 4.3 엔딩·에필로그
- 맵을 클리어하면 **캐릭터의 방식 엔딩**(E1~E4)이 해당 맵 배경으로 나온다.
- 에필로그 텍스트는 `캐릭터 × 맵 스타일` 16종 → **엔딩 도감 16칸**. 같은 맵을 다른 캐릭터로 다시 할 이유가 된다.
  - 예: 공병대장 × 범람원형 → "들판을 메워 둑을 쌓았다 / 갈대숲이 사라졌다"

```
┌─────────────────────────────┐
│ ❤ 100  💰 150  🌊 1/5     ⏸   │
│ [기지 수위 ▓▓░░░]              │
├─────────────────────────────┤
│              (맵)              │
├─────────────────────────────┤
│ [🌿①] [②⏱] [③⏱] [④▓▓░]  [▶]  │  스킬 4칸 (쿨다운 링 / 궁극기 게이지)
```

- 스킬 ②③은 버튼을 누른 뒤 **맵의 섹터/방향을 탭·스와이프**. 쓸 수 있는 대상만 하이라이트.
- 캐릭터마다 HUD 색만 바꾸고 레이아웃은 동일 → 캐릭터를 바꿔도 조작을 다시 익힐 필요 없음.

### 5.5 결과 화면
- 점수 내역(숙련·상성 보정·공통·첫 조합) + 캐릭터 경험치 + 에필로그 카드 2장(얻은 것/잃은 것).

## 6. 성장 (메타 진행)

| 요소 | 내용 | 주의 |
|---|---|---|
| 캐릭터 레벨 | 클리어 시 경험치 → 스킬 강화 (스킬당 3단계) | 강화 폭 제한(+20% 내외). 레벨로 "도전" 조합이 쉬워지면 보정 의미가 사라짐 → **상성 보정은 레벨과 무관하게 유지** |
| 스킬 변형 | 레벨 3에서 스킬 1개를 두 갈래 중 택1 (예: 모래주머니 벽 → 길게 / 두껍게) | 캐릭터 안에서의 선택 = 리플레이 가치 |
| 캐릭터 해금 | 처음엔 둑지기만, 첫 맵 클리어 후 나머지 3명 개방 | 첫 판의 선택 피로 줄이기 |
| 도감 | 엔딩 16칸, 맵 × 캐릭터 클리어 현황 | 전부 채우기 = 장기 목표 |

## 7. 종합 스테이지와의 관계 (선택)
이전 문서의 "합류점(종합 스테이지)"은 다음 중 하나로 흡수할 수 있다.

| 안 | 내용 |
|---|---|
| **A 태그 맵** | 특수 맵에서 **캐릭터 2명**을 데리고 들어가 웨이브 사이에 교대. 누구 비중이 컸는지로 엔딩 분기 |
| B 기존 구상 유지 | 캐릭터 1명 + 갈림길 카드로 4엔딩 분기 (캐릭터 방식과 다른 엔딩도 가능) |
| C 생략 | 엔딩은 캐릭터 × 맵 도감 16칸으로 대체 |

권장: 우선 **C로 출시 범위를 잡고**, 캐릭터 4명이 모두 안정되면 A를 후속 콘텐츠로.

## 9. 결정 필요 사항
1. 해석 확인: **캐릭터 4명 × 스킬 4개**가 맞는지 (또는 캐릭터 1명이 스킬 4개 중 일부를 고르는 방식인지)
2. 선택 순서: **맵 먼저(권장)** / 캐릭터 먼저
3. 스타일당 맵 수: 출시 시 스타일당 3장(총 12장) + 일일 시드 맵 제안
4. 종합 스테이지 처리: **C 생략 후 A 태그 맵 후속(권장)** / B 유지
5. 첫 구현 범위 — 권장: **캐릭터 2명(둑지기·습지 연구원) × 스타일 2종(평야·범람원) × 맵 2장씩**으로 상성·보정 구조를 먼저 검증
