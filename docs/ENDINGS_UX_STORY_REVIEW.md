## 1. 엔딩 정의

| # | 가칭 | 플레이 방식 | 현실 홍수관리 대응 개념 |
|---|---|---|---|
| E1 | **버틴 자들** (방어) | 자연은 건드리지 않고 제방·펌프만으로 물을 막음 | 전통적 제방 방어 |
| E2 | **콘크리트 왕국** (정복) | 숲 벌채·산 절개·하천 직강화로 자재·지형을 얻어 물을 막음 | 하드 엔지니어링 |
| E3 | **강에게 자리를** (공존) | 외곽 일부를 일부러 범람원으로 내어주고 생태를 살림 | 네덜란드 *Room for the River* — 범람원 복원, 제방 후퇴 |
| E4 | **물의 도시** (이주·활용) | 기지를 고지대로 옮기고, 물을 모아 저수·수력·관개로 활용 | 계획적 이전(managed retreat) + 빗물 활용 |

E3·E4는 실제 사례에 근거가 있다: Room for the River는 2007년부터 30여 곳에서 범람원을 복원하고 제방을 낮추거나 옮겼고, 제방만 높이면 홍수가 **다른 곳(하류)으로 밀려난다**는 문제의식에서 출발했다. 복원된 범람원에 멸종위기 조류가 돌아온 사례도 보고된다. ([Climate Central](https://www.climatecentral.org/news/the-dutch-are-giving-rising-rivers-more-room.-should-we-follow-suit), [Forest & Bird 보고서](https://www.forestandbird.org.nz/sites/default/files/2022-11/F%26B_Room-For-Rivers_Report_online_0.pdf)) → E2 에필로그의 "하류 피해", E3의 "새가 돌아옴" 연출에 그대로 쓸 수 있다.

## 3. 점수 체계 — "모든 선택에 가산점"

### 3.1 4개 성향 축 (게임 중 누적)

| 축 | 오르는 행동 | 주 엔딩 |
|---|---|---|
| 🛡 **수호** (Safety) | 기지 HP 유지, 제방·펌프 운용 | E1 |
| ⛏ **개척** (Conquest) | 벌채, 산 절개, 직강화, 콘크리트 제방 | E2 |
| 🌿 **공존** (Harmony) | 범람원 개방, 습지·숲 보존, 생물 복귀 | E3 |
| 💧 **활용** (Harvest) | 저류량, 수차 발전, 관개, 기지 이전 | E4 |

### 3.2 엔딩 판정
```
if 기지 이전 완료 and 활용 ≥ 임계  → E4
elif 개척 행동이 전체 행동의 40% 이상 → E2
elif 의도적 범람 구역 ≥ 1 and 공존 ≥ 임계 → E3
else → E1
(패배 = 기지 HP 0 → 엔딩 아님, 재도전)
```
- 판정은 단순하고 **플레이 중 미리 보인다**(5장 나침반). 실수로 원치 않는 엔딩이 나오지 않게.

### 3.3 점수 공식
```
총점 = 클리어 기본점(1000)
     + 루트 숙련 가산점(0~500)   ← 엔딩마다 다른 기준, 최대치는 동일
     + 공통 보너스(0~200)       ← 피해 최소, 시간, 노 리트라이
     + 첫 달성 보너스(+100)      ← 처음 보는 엔딩이면
```

| 엔딩 | 루트 숙련 가산점 기준 (각 최대 500) | 칭호 예시 |
|---|---|---|
| E1 버틴 자들 | 자연 무손상 × 시설 최소 수 × HP 잔존 | "최소 개입" |
| E2 콘크리트 왕국 | 물 차단 효율(차단량/자재) × 클리어 속도 × HP 100 | "철벽 설계" |
| E3 강에게 자리를 | 의도한 범람 구역 **외** 침수 0 × 생태 지수 × 희생 최소화 | "정확한 양보" |
| E4 물의 도시 | 저류량 × 이전 타이밍(늦을수록 위험·고득점) × 생산 에너지 | "물의 주인" |

- **설계 규칙**: 네 엔딩의 이론 최고점 차이 ±5% 이내 → 자동 테스트로 강제(7장).
- 점수는 **"얼마나 잘했나"**, 엔딩은 **"무엇을 택했나"**. 두 개를 섞지 않는다.

## 4. 게임 내 선택 수단 (배치 없는 UI와 연결)

브레인스토밍의 추천 조합(섹터 링/고정 거점 + 수문 토글 + 물 스킬)에 루트별 행동을 **같은 조작 방식**으로 얹는다.

| 루트 | 행동 | 조작 | 즉시 효과 | 대가 |
|---|---|---|---|---|
| E1 | 제방 강화, 펌프 가동 | 섹터 탭, 펌프 토글 | 기지 보호 | 자금 소모 큼 |
| E2 | **숲 벌채** | 숲 섹터 길게 누르기 | 자재 +, 큰 제방 해금 | 생태 −, 토사 유출(다음 웨이브 물이 탁해져 펌프 효율 −) |
| E2 | **산 절개** | 언덕 거점 탭 | 높은 방벽 | 산사태 이벤트 확률 |
| E2 | **직강화** | 수로 구간 탭 | 물이 빨리 빠짐 | 하류 피해(에필로그), 유속↑ |
| E3 | **범람원 개방** | 외곽 수문 열기 | 기지 쪽 수위↓ | 농지·외곽 시설 침수(자금 수입 −) |
| E3 | 습지 복원 | 범람원 탭 | 물 흡수 + 생물 복귀 | 준비 시간 필요 |
| E4 | **저류지 수문** | 저류지 수문 닫기/열기 | 물 저장(자원화) | 저류지 만수 시 월류 위험 |
| E4 | **기지 이전** | 중반 "이전 결단" 카드 → 고지대 후보 2곳 중 택1 | 이후 홍수 피해 대폭↓ | 이전 중 2웨이브간 방어력 저하, 기존 시설 일부 포기 |

- 모든 행동은 **큰 터치 목표**(섹터·거점·수문·카드)이며 좌표 선택이 없다.
- 행동 버튼에는 **축 아이콘만** 표시(🛡⛏🌿💧). 선악 색(빨강/초록)·"나쁜 선택" 경고 금지.

## 5. UX 구성

### 5.1 성향 나침반 (HUD)
4방향 홍수 테마와 맞춰 **4방위 나침반**으로 현재 성향을 표시한다.
```
          🛡 수호
            ▲
   ⛏ 개척 ◀ ● ▶ 🌿 공존       ● = 현재 성향(바늘)
            ▼                탭 → 엔딩 예측 카드
          💧 활용
```
- 탭하면 "이대로면 **E3 강에게 자리를**" + 다른 엔딩 조건 힌트("기지를 옮기면 E4 가능").
- 네 방향 색은 서로 다른 중립 색상(빨강/초록 배제).

### 5.2 갈림길 카드 (웨이브 사이, 스테이지당 2~3회)
```
┌──────────────────────────────┐
│ 상류 저수지가 한계에 다다랐다    │
│                              │
│ [⛏] 산을 깎아 둑을 쌓는다       │  → 자재 +40, 생태 −
│ [🌿] 북쪽 들판을 비운다         │  → 범람원 1구역, 수입 −10
│ [💧] 저수지 물을 끌어온다       │  → 저류량 +, 월류 위험
│ [🛡] 기존 제방을 보강한다       │  → 자금 −30
└──────────────────────────────┘
```
- 선택지마다 **이득·대가를 숫자로** 함께 표기. 선택은 축 점수와 맵 상태에 반영.
- 각 선택지를 해당 성향의 인물(6장)이 말하는 형식 → 이야기와 전략이 한 화면에.

### 5.3 결과 화면
```
┌──────────────────────────────┐
│   [엔딩 일러스트: 강에게 자리를]  │
│   "정확한 양보" 칭호 획득         │
│                              │
│   ◇ 4축 레이더 차트             │
│                              │
│ 클리어 기본       1000         │
│ 루트 숙련(공존)    +420         │
│  ├ 계획 외 침수 0  +200         │
│  ├ 생태 지수 92%   +160         │
│  └ 희생 1구역      +60          │
│ 공통 보너스       +150         │
│ 첫 달성          +100         │
│ ───────────────────────       │
│ 총점             1670         │
│                              │
│ 엔딩 도감 ●●○○  [다른 길로 재도전] │
└──────────────────────────────┘
```
- **엔딩 도감**(4칸): 수집 욕구 → 리플레이. 미달성 엔딩은 실루엣 + 한 줄 힌트.
- 재도전 시 "다른 길로" 버튼이 다음 엔딩 힌트를 보여주며 시작.

### 5.4 루트 해금 특전 (메타 진행)
엔딩을 달성하면 다음 스테이지에서 쓸 **그 루트 전용 특전**이 열린다 → 한 루트만 파도 손해가 없고, 다른 루트도 시도할 동기.

| 달성 엔딩 | 해금 특전 |
|---|---|
| E1 | 강화 제방 (내구도↑) |
| E2 | 중장비 (벌채·절개 속도↑) |
| E3 | 습지 정령 (범람원 흡수량↑) |
| E4 | 수차 (저류 → 자금 전환) |

### 5.5 피해야 할 UX
- 엔딩 직전에야 루트가 결정되는 "깜짝 판정" → 나침반·예측 카드로 상시 공개.
- 특정 루트에만 업적·별 3개 몰아주기.
- 텍스트로 플레이어를 훈계하기("당신이 자연을 파괴했습니다").

## 6. 스토리 구성

### 6.1 배경
해마다 장마가 거세지는 강 유역. 플레이어는 강 가운데 땅에 있는 **기지(마을의 마지막 거점)** 의 관리자. 올여름, 네 방향 물길이 동시에 불어난다.

### 6.2 네 명의 조언자 — 각자 한 루트의 목소리
판정자가 아니라 **신념이 다른 동료**. 누구도 악역이 아니다.

| 인물 | 루트 | 신념 한 줄 | 약점(대가를 스스로 앎) |
|---|---|---|---|
| 둑지기 *노장* | E1 수호 | "선 안쪽만 지키면 된다." | "언젠간 선이 모자랄 거야." |
| 공병대장 | E2 개척 | "산 하나로 마을 백 년을 산다." | "하류 사람들 얼굴은 안 보이지." |
| 습지 연구원 | E3 공존 | "강에게 자리를 내주면, 강도 우리를 비켜 간다." | "들판 주인에게 뭐라고 말하지?" |
| 수로 기술자 | E4 활용 | "물은 재앙이자 재산이다. 옮겨 앉으면 된다." | "떠나는 집은 다시 오지 않아." |

### 6.3 스테이지 3막 구조
| 막 | 웨이브 | 내용 |
|---|---|---|
| 1막 경고 | W1~W2 | 첫 비. 조언자 4명 소개, 각자 첫 행동을 무료로 체험(튜토리얼 겸 루트 맛보기) |
| 2막 갈림길 | W3~W4 | 상류 저수지 위기, 기지 이전 제안 등 갈림길 카드. 조언자 간 의견 충돌 대사 |
| 3막 대홍수 | W5 | 최대 홍수. 선택한 루트의 결과가 극적으로 드러남(제방 버팀/산사태 위기/범람원이 물을 삼킴/저류지 만수) |
| 에필로그 | — | "10년 후" 카드 2장: **얻은 것 1장 + 잃은 것 1장** |

### 6.4 엔딩 에필로그 (이득·대가 쌍)
| 엔딩 | 얻은 것 | 잃은 것 |
|---|---|---|
| E1 버틴 자들 | 마을은 그대로, 숲도 그대로 | 해마다 제방을 더 높여야 한다. 둑지기의 손이 늘 모자라다 |
| E2 콘크리트 왕국 | 다시는 기지에 물이 들지 않는다. 마을이 커졌다 | 민둥산과 곧은 강. 그해 하류 마을에 더 큰 물이 갔다 |
| E3 강에게 자리를 | 범람원에 새들이 돌아왔다. 홍수가 와도 물이 쉬어 간다 | 북쪽 들판은 더 이상 밭이 아니다. 몇 집은 생업을 바꿨다 |
| E4 물의 도시 | 고지대 새 기지, 저수지의 물로 가뭄도 넘긴다 | 옛 기지는 물속에. 떠난 사람들의 이름이 둑에 새겨졌다 |

### 6.5 캠페인 확장 (선택)
- 스테이지별 엔딩이 **세계 상태**로 누적: E2를 반복하면 다음 맵의 숲이 줄고 토사 유출 이벤트 증가, E3을 반복하면 습지 맵 해금 등.
- 최종 장에서 누적 성향에 따라 **캠페인 에필로그** — 여기서도 우열 없이 "당신이 만든 강 유역"을 보여준다.

## 7. 검증 계획

| 항목 | 방법 | 합격 기준 |
|---|---|---|
| 4엔딩 도달 가능 | 시뮬레이션 봇 4종(루트별 스크립트)으로 자동 플레이 | 4종 모두 클리어 |
| 점수 공정성 | 봇별 최고점 비교 | 최고점 차이 ±5% 이내 |
| 지배 루트 없음 | 난이도별 클리어율 | 루트 간 클리어율 차이 15%p 이내 |
| 판정 예측 가능 | 플레이테스트: 나침반 예측 vs 실제 엔딩 | 일치율 ≥ 90% |
| 처벌감 없음 | 플레이테스트 설문 "이 엔딩이 벌처럼 느껴졌나" | 평균 2/5 이하 |
| 리플레이 동기 | 1회 클리어 후 다른 루트 재도전률 | ≥ 50% |

데이터 구조 스케치:

state.axes = { safety: 0, conquest: 0, harmony: 0, harvest: 0 };

## 8. 결정 필요 사항
1. 엔딩 이름·인물 톤 (현재: 담담한 우화체)
2. 갈림길 카드 수(스테이지당 2 vs 3)
3. 캠페인 누적 세계 상태 도입 여부 (도입 시 스테이지 간 밸런스 비용 증가)
4. 첫 구현 범위 — 권장: **1스테이지 + 4엔딩 + 나침반 + 결과 화면**을 P1 프로토타입(섹터 링+수문)에 얹어 검증
