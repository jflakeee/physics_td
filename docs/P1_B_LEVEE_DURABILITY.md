# P1-B — 제방 내구도·침수 압력·붕괴

## 구현 범위
탑뷰 자연재해 프로토타입(`/legacy/`)의 제방에 내구도를 도입했다.

- 제방 건설 시 내구도 100.
- 각 시뮬레이션 틱마다 제방에 인접한 4개 칸 중 가장 높은 물 깊이를 확인.
- 물 깊이가 0.35 미만이면 피해 없음. 그 이상이면 `(최대 인접 물 깊이 - 0.35) × 0.8`만큼 내구도 감소.
- 내구도가 0이 되면 제방이 무너져 해당 칸이 물이 흐를 수 있는 칸으로 바뀜.
- UI에서 제방 내구도에 따라 색상을 변경하고 손상된 제방에는 잔여 내구도 막대를 표시.
- 재시도 체크포인트에 제방 내구도를 포함해 이전 상태로 복원.
- 압력에 따른 붕괴와 건조 시 유지, 재시도 복원을 자동 테스트로 추가.

## 설계상 주의
- 실제 구조공학 수압 계산이 아닌 게임용 근사치.
- 누수(완전 파괴 전 소량 유입), 수리, 강화, 자원 비용, 지형 고도에 따른 제방별 수압 차는 아직 미구현.
- 기존 `blocked` 통계 필드는 이번 단계에서 붕괴 횟수에 임시 재사용. 용어 정리는 별도 작업.
- 물이 제방에 닿아도 실제 압력 분포는 고려하지 않음.
