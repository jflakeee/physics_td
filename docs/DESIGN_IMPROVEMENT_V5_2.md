# Physics TD — 자연재해 중심 설계 개선 v5.2

## 목표
기존 적 처치형 TD에서 벗어나, **물의 흐름을 관찰하고 제어해 중앙 기지를 보호하는 전략 게임**으로 정체성을 강화한다. 현재 엔진은 격자 기반 단순 수위 확산으로, 실제 수압/지형 고도는 구현하지 않았다.

## 이번 개선 (P0)
- 탑뷰에서 '물길 보기'를 활성화하면 **실제 인접 셀 수위 차**를 기준으로 수류 방향 화살표를 그린다.
- 과거 적 경로 탐색 오버레이를 제거한다. 표시 방향은 실제 시뮬레이션 수위 기울기를 이용한 시각적 근사이며 유량 벡터 자체를 계측한 값은 아니다.
- 웨이브 기록·캠페인 통계에서 처치/적 도달/경로 차단 용어를 제외하고 침수 노출 틱 및 피해로 통일한다.
- 배수펌프 설치 미리보기 범위를 실제 엔진의 반경 2셀과 일치시킨다.
- 설치 안내를 탑뷰 홍수 방어 규칙에 맞춘다.

## 다음 설계 우선순위
### P1 — 물리·전략성
1. 고도맵: 지면 고도 + 수위로 물의 흐름을 결정하고 물길 변경의 전략성을 확보.
2. 제방 내구도: 수위 차에 따른 누수·파손, 수리·강화 및 우회 수로.
3. 배수펌프: 처리량/전력/배출 목적지 제한을 두어 무제한 물 삭제를 지양.
4. 자연재해 다양화: 강우·상류 범람·해일을 유입 위치, 시간, 유량 패턴으로 차별화.
5. 단계 종료 조건: 단순 제한시간 경과가 아닌 재해 종료 후 잔류 침수량·기지 안전 기준 검토.

### P2 — UX·품질
- 4방향 위험도 히트맵, 기지 수위 추이, 시설 효율 비교.
- 재도전 시 설치 비용/위험도 비교 및 웨이브 요약.
- 모바일 FPS/발열 측정, 접근성, 실제 브라우저 시각 검증.
- 구형 적 관련 내부 필드와 테스트 정리(레거시 엔진 보존 여부 별도 결정).

## 검증 기준
- `node --check src.js` 통과.
- `npm test`, `npm run build` 통과.
- GitHub Actions Pages 배포 성공 확인.
- 브라우저에서 실제 물길 화살표·통계·배치 범위의 표시를 별도 수동 검증.
- CI 통과만으로 브라우저 시각 검증 완료라고 표시하지 않는다.
