## 1. 게임 개요

- **장르**: 모바일 웹 물리 기반 자연재해 방어 (홍수 TD)
- **한 줄**: 네 방향에서 불어나는 물을, 서로 다른 신념을 가진 네 명의 방식으로 막고·나누고·비켜서고·활용한다.
- **세션**: 1판 5~7분, 5웨이브
- **핵심 재미**
  1. 물이 지형을 따라 실제로 흐르는 것을 보고 대응하는 **물리 퍼즐**
  2. 레벨업마다 다른 캐릭터의 스킬을 섞는 **빌드 드래프트**
  3. 어떤 방식이든 정당한 클리어가 되는 **가치 선택과 엔딩 수집**

---

## 2. 게임 흐름

```
타이틀
  └ 맵 선택 (스타일 탭 · 맵 카드)
      └ 브리핑 + 캐릭터 선택 (좌우 스와이프)
          └ 플레이 ─┬ 준비 단계 (시간 정지, 레벨업 정산, 스킬 사용 가능)
                    ├ 웨이브 진행 (1× / 2×)
                    └ ×5
          └ 결과 (점수 내역 · 엔딩 카드 · 도감)
              ├ [다른 캐릭터로 이 맵]
              ├ [다음 맵]
              └ [맵 선택]
```

- 첫 실행: 둑지기만 선택 가능, 평야 1번 맵에 "처음이라면 여기부터" 배지. 첫 클리어 후 습지 연구원(출시 범위) 개방.
- 패배(기지 HP 0): 결과 화면 대신 **실패 카드** — 침수 원인 방향 히트맵 + [이 웨이브부터 재도전] [처음부터].

## 3. 시뮬레이션 규칙

### 3.1 격자와 지형
| 항목 | 값 |
|---|---|
| 시뮬 격자 | 64 × 96 (세로형), 셀 단위 물 `w`, 얼음 `ice`, 지면고 `h` |
| 지면고 `h` | 0.0 ~ 3.0 (맵 데이터), 스킬로 변경 가능(절개·성토) |
| 구조물 | 셀별 `wall` 높이(제방), `dur` 내구도 |
| 고정 타임스텝 | 33ms (30 tick/s), 2× 배속 = 프레임당 2스텝 |
| 시간 단위 | 쿨다운·지속시간·충전은 모두 **게임 시간(tick)** 기준. 문서의 "초" = 30 tick. 배속을 올리면 쿨다운도 같은 비율로 빨리 돈다 |
| 준비 단계 | **시뮬레이션·쿨다운·지속 효과 모두 정지**. 스킬 사용은 가능하나 효과는 다음 웨이브 시작부터 진행(예: 습지 복원 10초는 웨이브 중에 경과) |

### 3.2 흐름 (현행 `fluids()` 확장)
```
수두 H_i = h_i + w_i + wall_i
flow(i→j) = min( w_i / 4,  max(0, (H_i − H_j)) × k )     k = 0.25 (안정성 상한 < 0.25)
```
- 제방은 `wall` 높이만큼 수두를 올려 **월류**가 자연스럽게 발생(물이 제방보다 높아지면 넘어감).
- 제방 내구도: 인접 셀 수위차 × 0.02/tick 감소, 0이면 붕괴(`wall=0`) + 토사 이벤트.
- 배출구 셀(맵 데이터): 매 tick `w −= 0.05`.
- 증발: 전 셀 `w −= 0.0002`.
- 얼음: 흐름 차단(수두 기여), 융해 0.0008/tick (현행 유지).
- 질량 보존 테스트: 배출·증발·펌프·유입을 제외한 순변화 0 (오차 1e-4).

### 3.3 기지 피해
```
flood = 기지 3×3 셀 수위 합
damage/tick = max(0, flood − 1.2) × 2      (현행 이진 판정 → 초과분 비례)
```
- 기지 HP 100. HUD에 `flood / 1.2` 게이지 상시 표시.

### 3.4 유입 (웨이브)
- 맵 데이터로 정의: 유입구 위치(2~4곳), 웨이브별 방향 가중치, 펄스 주기·양.
- 웨이브 시작 전 준비 단계에 **방향별 예고 화살표**(굵기 = 양).

## 4. 맵

### 4.1 구역(zone) — 좌표 대신 조작 단위
맵은 시뮬 격자 위에 6~12개의 **구역**으로 나뉜다. 모든 스킬은 구역·수문·거점을 대상으로 한다.

| 구역 타입 | 설명 | 대표 스킬 대상 |
|---|---|---|
| `plain` 평지 | 제방 건설 가능 | 제방 쌓기, 모래주머니 |
| `forest` 숲 | 물 흡수 약간, 자재 자원 | 벌채 |
| `hill` 언덕 | 지면 높음 | 산 절개 |
| `field` 들판 | 저지대 농지, 수입원 | 범람원 개방 |
| `wetland` 습지 | 물 흡수 강함 | 습지 복원 |
| `reservoir` 저류지 | 물 저장 | 수문 조작 |
| `base` 기지 | 보호 대상 | — |

추가 오브젝트
| 오브젝트 | 조작 주체 | 설명 |
|---|---|---|
| **일반 수문** (gate) | 모든 캐릭터 (공통 조작, 스킬 슬롯 아님) | 탭으로 개폐. 닫히면 높이 2.0 벽 |
| **저류 수문** (reservoirGate) | 수로 기술자 기본기 보유 시만 | 저류지 입·출구. 미보유 시 잠김 표시 |
| **펌프 거점** (pump) | 모든 캐릭터 (공통 스킬 💧) | 탭으로 가동/정지 |
| **제방선** (leveeLine) | 제방 쌓기·모래주머니 대상 | 구역마다 데이터로 지정된 1~3개 선분. 제방은 **이 선 위에만** 생긴다 |

- 제방 쌓기 탭 시: 그 구역의 제방선 중 **현재 유입 예고 방향에 가장 가까운 선**에 건설. 같은 구역을 다시 탭하면 다음 제방선, 모든 선이 지어졌으면 가장 낮은 제방을 높이 +0.3 (비용 동일).
- 모래주머니 벽(스와이프): 경로를 시뮬 셀에 스냅, 폭 2셀. 경로 길이 최대 24셀(초과분 무시). 기지·유입구 3셀 이내는 생성 안 됨.
- 구역 최소 터치 면적: 세로 390px 화면 기준 **56×56px 이상**. 구역 경계는 탭 시 하이라이트.

| ⛏ 공병대장 | 자원 채취 자재 +50% | 벌채 (`forest` → `plain` + 자재) | 산 절개 (`hill` 지면고 −1.0, 인접 제방 +1.0) | 직강화 (배출구 유량 ×2, 유속↑) |
| 💧 수로 기술자 | 저류된 물 → 자금 | 저류 수문 조작 (**저류 수문** 개폐 권한, 일반 수문과 별개) | 물길 돌리기 (스와이프 방향 흐름 가중) | 기지 이전 (맵 데이터의 고지대 이전지로. 이전 중 1웨이브 동안 기지가 "이동 중" — 피해 판정 없음 대신 그 웨이브 무피해 점수 없음. **HP는 유지**) |

- 확장 캐릭터 두 명은 출시 전에 이 표의 스킬 효과를 5.2·5.3 수준의 수치표로 확정한다(미결 사항 23장).
- 기지 이전 궁극기는 이전지가 없는 맵에서는 **사용 불가**로 표시되고, 레벨업 카드에도 나오지 않는다.

### 5.5 슬롯 규칙
- 시작(Lv1): 공통 2 + 자기 패시브 + 자기 기본기
- 액티브 슬롯 4칸(기본기 포함), 패시브 슬롯 3칸
- 교차 스킬: 다른 캐릭터의 **패시브·기본기·전술기**만, 교차 액티브 **최대 2칸**, 교차 스킬 **Rank1 고정**
- 자기 스킬 강화: Rank3까지 (레벨업 카드로)

## 6. 경험치·레벨업

### 6.1 플레이 점수 = 경험치
| 점수원 | 값 | 주 방식 |
|---|---|---|
| 배수량 (펌프·배출구) | 물 1.0당 +2 | 공통 |
| 무피해 시간 | 무피해 10 tick마다 +3 | 방어 |
| 제방 차단 | 제방이 막은 유량 1.0당 +2 | 방어 |
| 생태 회복 | 생태 지수 +1%당 +8 | 공존 |
| 자재 확보 | 자재 1당 +1 | 개척 (확장) |
| 저류·생산 | 저장 1.0당 +2 | 활용 (확장) |
| 웨이브 클리어 | +100 | 공통 |

- 목표: 정석 조합 평균 플레이 **1100~1300점/판** → 방식별 차이 ±10% 이내(봇 검증).

### 6.2 레벨 곡선
```
필요 경험치(Lv→Lv+1) = round(100 × 1.35^(Lv−1))
Lv2 100 · Lv3 135 · Lv4 182 · Lv5 246 · Lv6 332 · Lv7 448
누적: Lv6 = 995, Lv7 = 1443
```
- 평균 플레이 Lv6~7 도달(레벨업 5~6회).
- **마지막 웨이브(W5) 중 레벨업**은 카드를 고를 기회가 없으므로, 레벨당 **+50 결과 점수**("막판 성장")로 전환. 레벨업 대기 배지에 "최종 웨이브: 점수로 전환" 표시.

### 6.3 레벨업 정산
- 웨이브 중 레벨업 → 상단 **[⬆●●] 대기 배지**만 표시.
- 웨이브 종료(준비 단계)에서 대기 수만큼 카드 선택 연속 진행.
- 배지 탭 → 일시정지 후 즉시 선택(옵션, 설정에서 숨김 가능).

### 6.4 카드 생성 규칙
```
카드 3장 = 자기 1장 (미보유 자기 스킬 또는 자기 스킬 강화)
         + 교차 2장 (서로 다른 캐릭터 우선, 맵 스타일 정석 캐릭터 가중 ×1.5)
제외: 다른 캐릭터 궁극기, 교차 액티브 2칸이 찬 경우 교차 액티브, 이미 보유한 교차 스킬,
      현재 맵에서 대상이 없는 스킬(예: field 구역이 없는 맵의 범람원 개방)
```
- **상성 가중 예외**: 플레이어가 그 맵의 **도전 캐릭터**일 때는 정석 캐릭터 가중(×1.5)을 끈다. 도전 조합이 정석 스킬을 쉽게 빌려 사실상 정석이 되면서 +200 보정까지 받는 이중 이득을 막기 위함(부록 A-3).
- **후보 부족 시 대체 카드** (자기 스킬 전부 Rank3, 교차 후보 소진 등):
  | 대체 카드 | 효과 |
  |---|---|
  | 보급 | 자금 +60 |
  | 응급 보수 | 기지 HP +10 (최대 100) |
  | 정비 | 공통 스킬 쿨다운 −15% (판 동안, 최대 2회 중첩) |
- 대체 카드는 성향 축·빌드 유형에 영향 없음.
- **건너뛰기**: 즉시 자금 +40, 판 종료 시 절제 보너스.
- **다시 뽑기**: 판당 1회.
- 액티브 슬롯이 가득 찬 상태에서 액티브를 고르면 교체 대상 선택.
- **희귀도·천장·스파이크 보장** (24.2, 24.5): 카드마다 일반 70 / 희귀 25 / 전설 5% (확률 ⓘ 공개). 레벨업 4회 안에 융합 카드가 없으면 다음 1장 보장. Lv3 카드에 자기 전술기, Lv5 카드에 자기 궁극기(미보유 시) 보장 — "자기 1장" 자리를 사용.

### 6.5 융합 효과 (출시 1종 + 확장 5종)
| 조합 | 효과 | 출시 |
|---|---|---|
| 🛡 제방 쌓기 + 🌿 습지 복원 | **녹색 제방**: 제방 바로 안쪽 셀이 흡수 0.003/tick, 누수 감소 | ✅ |
| ⛏ 벌채 + 🌿 습지 복원 | 통나무 둑 | 확장 |
| ⛏ 산 절개 + 💧 수문 조작 | 계곡 저수지 | 확장 |
| 🛡 모래주머니 벽 + 💧 물길 돌리기 | 유도벽 | 확장 |
| 🌿 범람원 개방 + 💧 저류→자금 | 논 관개 | 확장 |
| 🛡 패시브 + ⛏ 패시브 | 석축 | 확장 |

- 레벨업 카드에 "✨ 융합 가능" 표시, 첫 발동 시 연출 + 도감 등록.

## 7. 점수

### 7.1 결과 점수
```
결과 점수 = 플레이 점수 (≈ 경험치 총합)
          + 클리어 보너스            500
          + 상성 보정                정석 0 / 보통 100 / 도전 200
          + 빌드 보너스              0 ~ 300  (장인 / 융합 / 절제 중 해당 유형)
          + 기지 보너스              남은 HP × 2
          + 첫 조합 보너스           50  (이 맵을 이 캐릭터로 첫 클리어)
          + 완주 보너스              100 (웨이브 재도전 없이 클리어)
          + 막판 성장                W5 중 레벨업 × 50
          + 위험 계약 보너스          무피해로 끝낸 계약 웨이브 × 80   (24.2)
          + 뮤테이터 배율             켠 변형 규칙 1개당 ×1.10, 최대 3개 (확장, 24.3)
```
- **감점 항목은 없다.** 재도전·HP 손실·도전 조합은 보너스를 덜 받을 뿐, 깎이지 않는다(부록 A-1).
- 경험치는 **플레이 점수만** 반영(클리어·상성·빌드 등 결과 보너스는 경험치가 아님).

### 7.2 빌드 보너스
| 유형 | 판정 | 공식 (상한 300) |
|---|---|---|
| 장인 | 교차 스킬 0개 | 자기 스킬 Rank 합 × 30 |
| 융합 | 교차 스킬 ≥ 2개 | 교차 출처 캐릭터 수 × 80 + 발동 융합 수 × 100 |
| 절제 | 건너뛰기 ≥ 2회 | 건너뛴 횟수 × 90 |
| (해당 없음) | 위 조건 미충족 | 교차 스킬 수 × 60 |

- 여러 유형을 동시에 만족하면 **가장 높은 것 1개**.
- **콘텐츠 규모에 따른 정규화**: 위 공식의 원점수를 "현재 콘텐츠에서 그 유형의 이론 최대치"로 나눈 뒤 300을 곱한다.
  ```
  빌드 보너스 = min(300, 300 × 원점수 / 유형별_이론최대(현재 캐릭터 수, 융합 수, 판당 레벨업 수))
  ```
  - 출시 범위(캐릭터 2명, 융합 1개)에서 원공식의 최대치는 장인 240(Rank 합 8×30), 융합 180(80+100), 절제 300 이상으로 **불균형**하다 → 정규화로 세 유형 모두 300 도달 가능하게 맞춘다(부록 A-4).
  - 이론 최대치는 데이터에서 자동 계산(`scoring.ts`)하고 테스트로 고정.
- 공정성 목표: 정석·도전, 장인·융합·절제 조합별 기대 최고 결과 점수 차이 ±5%.

## 8. 엔딩

### 8.1 성향 축
축은 스킬 데이터의 `axis` 필드. 공통 스킬·대체 카드는 축 없음.

**축 점수 계산** — "사용 횟수 +1"은 쿨다운이 짧은 기본기만 과대 반영하고, 사용하지 않는 패시브는 0이 되어 "레벨업 선택 = 엔딩 선택" 원칙과 충돌한다(부록 A-5). 따라서:
```
획득 시      : +3 (패시브·액티브 공통, 강화 시 +1)
액티브 사용 시: + 쿨다운(초) / 10      (기본기 비용형은 +1)
패시브 보유  : 웨이브 종료마다 +1
```
- 예: 모래주머니 벽(쿨다운 25초) 1회 사용 = +2.5, 숨 쉬는 땅(패시브) 5웨이브 보유 = +3 + 5.

| 축 | 소속 스킬 |
|---|---|
| 🛡 수호 | 둑지기 스킬 |
| ⛏ 개척 | 공병대장 스킬 |
| 🌿 공존 | 습지 연구원 스킬 |
| 💧 활용 | 수로 기술자 스킬 |

### 8.2 판정
```
주 성향 = 플레이 캐릭터의 축
부 성향 = 나머지 축 중 최댓값 (주 성향 사용량의 30% 이상일 때만)
엔딩 = (캐릭터, 부 성향 or 없음)
```
- 출시 범위 엔딩 4종: 둑지기 단독 / 둑지기+공존 / 습지 연구원 단독 / 습지 연구원+수호
- 전체(확장 후): 4 캐릭터 × (단독 + 부 성향 3) = **16종** 엔딩 도감

### 8.3 에필로그 카드 (얻은 것 + 잃은 것)
| 엔딩 | 얻은 것 | 잃은 것 |
|---|---|---|
| 둑지기 단독 "버틴 자들" | 마을도 숲도 그대로 | 해마다 제방을 더 높여야 한다 |
| 둑지기 + 공존 "녹색 제방의 마을" | 제방 안쪽에 갈대가 자라 물을 머금는다 | 제방 밖 들판 일부는 다시 강의 것이 되었다 |
| 습지 연구원 단독 "강에게 자리를" | 범람원에 새들이 돌아왔다 | 북쪽 들판은 더 이상 밭이 아니다 |
| 습지 연구원 + 수호 "지켜진 습지" | 마을과 습지가 함께 남았다 | 둑을 지키는 손이 늘 부족하다 |

- 나침반: HUD 🧭 탭 → 현재 성향과 예상 엔딩 표시(판 중 상시 확인 가능).

## 16. 측정 정의 (점수·엔딩에 쓰이는 수치)

| 지표 | 정의 |
|---|---|
| **생태 지수** | `Σ(숲·습지 셀의 건강도) / 맵 시작 시 Σ(숲·습지 셀 수)` × 100%. 건강도 0~1. 셀 수위 ≥ 0.5가 10초 지속되면 숲 건강도 −0.1/초(습지는 영향 없음). 습지 복원으로 생긴 셀은 건강도 1로 추가 → **100% 초과 가능(최대 150%)** |
| **제방 차단량** | 매 tick `Σ(제방 셀) min(인접 상류 수심, 제방 높이) × 0.01` |
| **배수량** | 펌프·배출구·습지 흡수로 제거된 물의 합 |
| **기지 수위** | 기지 3×3 셀 수위 합 (피해 임계값 1.2) |
| **무피해 시간** | 기지 피해가 0인 연속 tick |

- 모든 지표는 `sim/metrics.ts`에서 tick마다 누적, 결과 화면과 봇이 같은 함수를 사용.

## 19. 스토리·캐릭터

### 19.1 배경
해마다 장마가 거세지는 큰 강의 유역. 강가 마을들은 각자의 방식으로 물과 싸우거나 타협해 왔다. 올여름, 네 방향 물길이 동시에 불어난다. 유역을 돌아다니며 마을을 돕는 네 사람이 있다.

### 19.2 캐릭터
| 캐릭터 | 색 | 한 줄 소개 | 신념 | 스스로 아는 대가 |
|---|---|---|---|---|
| 🛡 둑지기 (노장) | 황토 | 40년째 둑을 지킨 사람 | "선 안쪽만 지키면 된다." | "언젠간 선이 모자랄 거야." |
| 🌿 습지 연구원 | 청록 | 범람원의 새를 세는 학자 | "강에게 자리를 내주면, 강도 우리를 비켜 간다." | "들판 주인에게 뭐라고 말하지?" |
| ⛏ 공병대장 | 주황 | 산을 깎아 도시를 지어 온 기술자 | "산 하나로 마을 백 년을 산다." | "하류 사람들 얼굴은 안 보이지." |
| 💧 수로 기술자 | 남색 | 물길과 저수지를 설계하는 사람 | "물은 재앙이자 재산이다." | "떠나는 집은 다시 오지 않아." |

색은 서로 구분되는 중립 계열(빨강·초록 배제), 색약 대비 아이콘 병행.

### 19.3 이야기 전달 지점 (짧게, 건너뛸 수 있게)
| 지점 | 형식 | 분량 |
|---|---|---|
| 브리핑 | 선택한 캐릭터의 맵 한마디 | 1줄 |
| 웨이브 시작 | 캐릭터 대사 토스트 | 1줄, 2초 |
| 교차 카드 | **원 소유 캐릭터의 한마디** ("내 방식을 써 보겠다고? 좋아.") | 카드 하단 1줄 |
| 융합 첫 발동 | 두 캐릭터 대화 | 2줄 |
| 결과 | 에필로그 카드 2장(얻은 것/잃은 것) | 각 1~2문장 |

- 이야기는 **판 단위로 완결**(캠페인 서사 없음, 출시 범위). 캐릭터 숙련도 단계마다 그 캐릭터의 짧은 회고 카드 해금(성장감 24.4).

| **도박성** (위험을 걸고 보상을 노리는 긴장) | **2** | 무작위는 레벨업 카드 3장뿐. 시뮬레이션은 결정적이고, 플레이어가 **스스로 위험을 거는 선택**이 없음 | 위험-보상 베팅, 카드 희귀도의 설렘 |
| **중독성** (한 판 더) | **3** | 5~7분 짧은 판, 엔딩·융합 도감, 다른 캐릭터로 재도전 버튼 | 판이 끝날 때 "다음 판의 목표"가 약함, 매일 돌아올 이유 없음 |
| **의외성** (예상 밖의 순간) | **2** | 물리의 창발적 흐름, 융합 발견. 하지만 웨이브는 예고대로만 진행, 융합 조합이 카드에 미리 표시됨 | 판 중 돌발 사건, 숨겨진 발견 |
| **성장감** | **3** | 판 안 Lv1→7은 뚜렷. 영구 진행은 능력치가 없어 **장기 성장 체감이 약함** | 파워 스파이크 시점, 눈에 보이는 영구 변화 |

### 24.2 도박성 개선 — "스스로 고르는 위험"

| 장치 | 규칙 | 효과 |
|---|---|---|
| **위험 계약** | 준비 단계에서 선택(기본 OFF). 이번 웨이브 유입 +30% ↔ 이번 웨이브 경험치 ×1.5, 무피해 시 계약 보너스 +80 | 플레이어가 고르는 베팅. 실패해도 감점 없음(보상만 놓침) |
| **카드 희귀도** | 일반 70% / 희귀 25% / 전설 5%. 희귀 = 강화 2단계 한 번에 또는 융합 완성 카드, 전설 = 숙련도로 해금된 스킬 변형. **확률은 카드 화면 ⓘ에 공개** | 카드 공개 순간의 설렘 |
| **기상 예보 확률** | 예고에 확률 표시: "W4 폭우 60%". 실제 발생은 시드로 결정 | 대비 vs 운에 맡기기의 판단 |
| **천장(보장)** | 레벨업 4회 안에 융합 가능 카드가 한 번도 안 나오면 다음 카드 1장을 융합 카드로 보장 | 운이 나빠 빌드가 막히는 좌절 방지 |

**윤리 가드레일 (필수)**
- 현금·유료 재화와 무작위 보상을 **절대 연결하지 않는다**(확률형 아이템·뽑기 없음).
- 모든 확률 공개, 재도전 시 같은 시드(20장) → "될 때까지 다시" 악용·강박 차단.
- 위험 계약은 기본 OFF, 실패 시 감점 없음.

### 24.3 중독성 개선 — "다음 판의 이유"를 결과 화면에서 준다

| 장치 | 규칙 |
|---|---|
| **다음 목표 카드** | 결과 화면에 가장 가까운 목표 1개 자동 제시: "녹색 제방 융합까지: 습지 복원 1회", "⭐3까지 120점", "숙련도 다음 단계까지 300점" |
| **1탭 재시작** | [같은 맵 다시](같은 캐릭터, 새 시드) 버튼을 결과 화면 최상단에 |
| **오늘의 유역** | 날짜 시드로 맵·캐릭터·변형 규칙 1개 고정(예: "펌프 비용 2배"), 로컬 최고 기록. 서버 없음 |
| **변형 규칙(뮤테이터)** | 숙련도로 해금, 켜면 결과 점수 +10%씩(최대 3개): 폭우의 해, 비싼 자재, 좁은 제방선 등 |
| **자연스러운 종료점** | 판이 끝날 때마다 깔끔한 정지 지점. **에너지·스태미나 제한, 연속 접속 보상 끊김 처벌, 알림 압박 없음** |

### 24.4 의외성 개선 — 판 중 사건과 숨은 발견

| 장치 | 규칙 |
|---|---|
| **돌발 사건** | 웨이브마다 20% 확률(시드), 발생 3초 전 예고 토스트. 맵 스타일별 풀: 제방 균열(가장 압력 큰 제방 내구도 −40%), 상류 산사태(유입 방향 하나가 이웃 방향으로 이동), **비버 댐 출현**(무작위 숲 구역에 낮은 둑 생성 — 도움), 철새 도래(습지 생태 +10%), 돌풍(얼음 빠르게 융해) |
| **숨은 융합** | 도감에 "???"로 표시, 카드에는 첫 발견 전까지 "✨ 무언가 일어날 것 같다"만 표시 |
| **비밀 엔딩 "합류"** | 조건: 4축(출시 범위는 2축) 점수 차이 20% 이내 + 무피해 클리어. 처벌 없는 숨은 보상(도감 1칸 추가) |
| **맵 비밀** | 맵마다 1개: 특정 구역 물을 뺐을 때 드러나는 옛 수로(배출구 추가) 등. 발견 시 도감 기록 |
| **명장면** | 월류·붕괴·비버 댐 등 극적인 순간을 자동 기록 → 결과 화면에 리플레이 3초(명령 로그 기반) |

- 돌발 사건은 **도움 사건과 위기 사건 비율 1:1**, 위기 사건은 대응 가능한 예고 시간 보장.

### 24.5 성장감 개선 — 판 안 스파이크 + 보이는 영구 변화

| 장치 | 규칙 |
|---|---|
| **파워 스파이크 보장** | Lv3 카드에 자기 전술기(미보유 시) 보장, Lv5 카드에 자기 궁극기(미보유 시) 보장 → 판 중반·후반 체감 지점 고정 |
| **강화 외형 변화** | Rank2·3에서 제방·습지·모래주머니 외형이 바뀜 |
| **캐릭터 숙련도 10단계** | 누적 플레이 점수로 상승. 단계 보상: 스킬 변형 카드(2·5·8단계), 뮤테이터(3·6단계), 의상(4·9단계), 회고 스토리 카드(매 단계), 칭호(10단계). **능력치 없음 유지** |
| **유역 지도 복원** | 맵 선택 화면 배경 = 유역 그림. 맵을 클리어할 때마다 그 맵의 엔딩 모습(제방·습지 등)이 지도에 그려지고, 도감이 찰수록 마을·새·배가 늘어남 |
| **기록 비교** | 결과 화면에 이 맵·캐릭터 직전 최고점 대비 ±표시, 레벨 도달 기록 |
