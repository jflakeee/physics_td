# P1-C — 펌프 전력 슬롯 1차 구현 (2026-11-11)

## 적용 위치
메인 v2 엔진 `src/sim/sinks.ts`, `src/sim/config.ts`, `src/core/types.ts`. Legacy 프로토타입은 변경하지 않았다.

## 현재 구현
- 기존 펌프는 이미 유량 상한(`pumpBudget`, `pumpRate`), 동시 가동 수(`pumpMaxOn`), 현금 운영비와 잔고 소진 자동 정지가 있다.
- 신규 `pumpPowerCapacity` 설정은 동시에 가동할 수 있는 펌프 전력 슬롯 수를 제한한다. 펌프 1대당 슬롯 1개.
- 실제 동시 가동 상한은 `min(pumpMaxOn, pumpPowerCapacity)`.
- 기본값 2로 기존 동시 가동 제한 2와 같아 기존 플레이를 바꾸지 않는다.
- 설정이 없는 이전 런타임 상태는 `pumpMaxOn`을 대체값으로 사용한다.
- 기존 HUD가 처리하는 `maxOn` 거절 코드를 그대로 사용한다. 향후 별도 전력 부족 안내를 추가할 수 있다.
- 단위 테스트: 전력 슬롯 1일 때 두 번째 펌프 거절, 첫 번째 정지 후 두 번째 가동.

## 아직 구현하지 않은 것
- 전력 생산/저장/충전, 정전, 발전기 시설, 펌프별 전력 소비량, 실시간 전력 계기판.
- 펌프 배출 목적지의 UI 선택, 재유입 경로 제어, 파이프 연결, 배출구 막힘. (엔진 수준의 선택적 맵 내부 배출은 2차 구현 완료)
- 전력 슬롯 값을 플레이어가 조작하는 UI와 저장 포맷 변경.
- 실기 플레이 밸런스 검증.

## 후속 계획
1. 기존 `drained` 지표와 물량 보존식을 바탕으로 외부 배출 vs 맵 내부 재배치의 물리 규칙을 결정.
2. 재배치형 펌프를 추가한다면 목표 셀 용량, 넘침, 저장 호환성, 재유입 테스트를 먼저 설계.
3. 전력 슬롯 증가를 스킬/맵 특성과 연동할 때 HUD 메시지와 경제 밸런스를 검증.

## 검증 원칙
커밋/CI/Pages 배포/실제 브라우저 플레이는 각각 독립 상태로 보고한다.

## 2차 구현: 배출 목적지 (2026-11-11)
- `setPumpDischarge(world, id, cell)`로 펌프별 맵 내부 배출 셀을 지정할 수 있다. `null`이면 종전과 동일하게 맵 밖으로 배출한다.
- 맵 내부 배출 시 원래 칸에서 제거한 물을 목적지 셀로 이동시켜 물량을 보존한다. 이 물량은 `metrics.drained`에 포함하지 않는다.
- 배출 셀 수심이 `pumpDischargeCellCap`(기본 2.0)에 도달하면 펌프가 추가로 물을 옮기지 못한다.
- 펌프 자신이 있는 셀과 목적지가 같으면 해당 셀은 펌핑 대상에서 제외한다.
- 기존 펌프의 기본값은 맵 외부 배출이며, 기존 유량·운영비 규칙은 유지한다.
- 테스트: 배출 용량, 물량 보존, 잘못된 목적지 거부, 외부 배출 복귀.
- 아직 UI에서 목적지 선택 기능, 파이프/거리 제약, 목적지 표시, 실제 브라우저 조작 검증은 미구현이다.
