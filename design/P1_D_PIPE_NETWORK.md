# P1-D — 배수 파이프 연결 시스템 설계 검토

기준: 2026-11-11, 메인 v2. P1-C 구현을 보존하고, 파이프 건설 기능은 **아직 미구현**이다.

## 기존 기능
- 펌프는 지정 반경의 물을 흡입한다.
- 맵 외부 배출 또는 지정 셀로 재배치한다.
- 재배치는 물량 보존, 배출 셀 수심 한도, 최대 직선거리 24셀을 따른다.
- 전력 슬롯·펌프 운영비·기존 웨이브 명령 큐를 사용한다.

## 권장 MVP 규칙
1. **연결 방식:** 펌프→배출구 1:1 연결. 별도 분기·합류·교차 파이프는 MVP에서 제외.
2. **배치:** 펌프를 선택하고 배출구를 터치하면 경로 미리보기를 보여준다. 직선거리 제한은 유지하되 실제 설치 시 맨해튼 길이 기반 비용을 별도 계산한다.
3. **경로:** 4방향 타일을 연결하는 최단 경로. 제방·건물·수역을 통과할 수 있는지 지형별 명시적 규칙 필요. 통과 불가 구간은 경로 탐색으로 우회.
4. **유량:** 기존 펌프 `pumpBudget`·`pumpRate`를 상한으로 유지. 파이프는 이보다 큰 유량을 만들지 않음.
5. **포화:** 목적지 수심이 한도에 도달하면 펌프가 멈춘 것처럼 유량 0. 운영비는 기존 정책에 따라 계속 부과되므로 UI 경고 필요.
6. **경제:** 파이프 길이당 설치비와 환불 정책을 GDD 승인 후 확정. 현재 임의 가격 적용 금지.
7. **저장:** 경로 타일을 체크포인트에 보관해야 재도전 시 시각적·물리적 일관성 유지. 기존 `pumpDischarges?` 필드 누락 시 외부 배출 유지.
8. **UX:** 모바일에서 연결 경로, 배출 포화, 전력 부족, 거리 초과를 서로 다른 메시지로 표시. 연결 취소·외부 배출 복귀 지원.

## 개발 순서
- D1: 경로 탐색 함수 + 결정적 테스트(직선/우회/차단/맵 경계).
- D2: 비용·유량·건설 규칙 승인.
- D3: 경로 미리보기·확정/취소 UI.
- D4: 저장·재도전·모바일 실기 회귀 검증.

## 출시 전 검증 기준
- 물량 보존 오차 허용치, 30TPS 성능, 파이프 경로 재현성, 이전 저장 호환성, 배포 SHA 일치.
- 테스트 성공과 실기 플레이 성공을 별도 기록.

## D1 구현 결과
- `src/sim/pipeRoute.ts`: BFS 기반 4방향 최단 경로 탐색. 이웃 순서 동→남→서→북으로 결정적 경로를 보장한다.
- 벽·임시벽·닫힌 게이트·기지 코어를 통과할 수 없다. 단 선택된 시작/끝점은 예외다.
- `maxLength`는 경로 간선 수 상한이며 초과 시 `null`을 반환한다.
- `tests/unit/sim/pipe-route_test.ts`: 직선, 장애물 우회, 길이 제한, 차단, 잘못된 좌표, 코어 통과 방지.
- **주의:** 경로는 미리보기용 순수 계산 결과다. 아직 펌프의 물리적 배출을 경로 존재 여부에 종속시키지 않았고 건설 비용·경로 저장·화면 렌더링도 구현하지 않았다.

## D2 — 모바일 경로 미리보기(실험적)
- 펌프 선택 후 포인터 이동 시 `findPipeRoute`로 계산한 최단 경로를 노란 점선으로 표시한다.
- 경로가 차단되면 목적지 확정을 거부하며 메시지를 표시한다. 직선거리 상한도 터치 확정 전에 검사한다.
- **구현 범위:** 시각적 미리보기와 터치 시 경로 존재 검증만. 경로 타일은 건설·저장되지 않으며 파이프 비용도 부과되지 않는다. 현재 펌프의 물 이동은 기존 목적지 재배치 방식이다.
- 이전 CI 실패(실행 43025126299): BFS 결정적 동률 해소가 아래쪽 우회 경로를 택했으나 테스트가 위쪽 경로를 기대한 오류. 실제 탐색 결과에 맞게 테스트 기대값 수정 후 재검증 대기.

## D3 — 배출 경로 확정 안전장치
- 목적지 터치 시 연결 길이(4방향 경로의 간선 수)를 표시하고 확인/취소를 받는다.
- 확인 후 기존 `pumpDischarge` 명령으로만 목적지를 변경한다. 취소 시 기존 배출 설정·현금을 변경하지 않는다.
- 실제 명령 실행 시점에 다시 경로 연결성을 검증해, 웨이브 명령 큐 사이 지형이 변한 경우에도 막힌 경로가 적용되지 않도록 한다.
- **경제 정책 미승인:** 설치 비용·환불·파이프 타일 건설은 여전히 미구현이며, 확인창에 이를 명시한다.
- CI 및 실제 모바일 터치 검증 결과는 별도로 기록해야 한다.

## D4 — 파이프 경제 정책 제안 (승인 전, 미구현)
- 건설비: **기본 5 + 경로 1칸당 2** 게임 내 화폐 (검토용 가설). 경로 길이는 BFS 간선 수 기준.
- 재배치: 이전 설치비 환불 없음 / 신규 경로 전체 비용. 빈번한 변경을 억제하지만 초보자 부담이 있으므로 실제 플레이 검증 필요.
- 취소: 확인창에서 취소한 경우 0원, 기존 경로 유지.
- 외부 배출 복귀: 무료. 기존 게임의 기본 기능이므로 추가 비용 금지.
- 경제 검증: 웨이브 1~5 평균 수입 대비 설치비, 첫 펌프 설치 후 잔액, 재시도 악용, 게임 초반 막힘 여부를 측정하기 전까지 **실제 차감 로직 도입 금지**.

## 모바일 UX 보완
- 드래그는 노란 점선 경로의 미리보기이며, 목적지 터치로만 확정한다는 안내를 추가했다.
- 배출구 포화 상태에 처음 진입할 때 한 번 알리고, 포화 해제 후 다시 포화되면 재알림한다.
- 실제 휴대전화 브라우저의 터치·시각 검증은 미실시.

## D5 — 모바일 회귀 점검 체크리스트
- 펌프 미선택 → 지도 터치 시 안내, 기존 명령 변경 없음.
- 펌프 선택 → 포인터/손가락 이동으로 경로 미리보기 → 손을 떼도 자동 확정하지 않음.
- 목적지 터치 → 확인창 취소 시 배출 경로·현금 유지, 확인 시 배출 경로 변경.
- 차단/거리 초과 → 경로 확정 거부, 기존 배출 경로 유지.
- 웨이브 도중 변경 → 명령 큐에 저장 후 적용 시 경로 재검증.
- 배출구 포화 → 켜진 펌프에 대해서만 1회 알림, 포화 해제/펌프 꺼짐 후 재포화 시 다시 알림.
- 체크포인트 재시도 및 이전 체크포인트 로딩 → 배출 위치 호환성 유지.
- 저사양 모바일 30TPS, 세로 화면, 터치 취소, 브라우저 뒤로가기: **실기 미검증**.
