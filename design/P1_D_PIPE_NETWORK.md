# P1-D — 배수 파이프 연결 시스템 설계 검토

기준: 2026-11-11, 메인 v2. P1-C 구현을 보존하고, 파이프 건설 기능은 **아직 미구현**이다.

## 기존 기능
- 펌프는 지정 반경의 물을 흡입한다.
- 맵 외부 배출 또는 지정 셀로 재배치한다.
- 재배치는 물량 보존, 배출 셀 수심 한도, 최대 직선거리 24셀을 따른다.
- 전력 슬롯·펌프 운영비·기존 웨이브 명령 큐를 사용한다.

## 권장 MVP 규칙
1. **연결 방식:** 펌프→배출구 1:1 연결. 별도 분기·합류·교차 파이프는 MVP에서 제외.
2. **배치:** 펌프를 선택하고 배출구를 터치하면 경로 미리보기를 보여준다. 직선거리 제한은 유지하되 실제 설치 시 맨해튼 길이 기반 비용을 별도 계산한다.
3. **경로:** 4방향 타일을 연결하는 최단 경로. 제방·건물·수역을 통과할 수 있는지 지형별 명시적 규칙 필요. 통과 불가 구간은 경로 탐색으로 우회.
4. **유량:** 기존 펌프 `pumpBudget`·`pumpRate`를 상한으로 유지. 파이프는 이보다 큰 유량을 만들지 않음.
5. **포화:** 목적지 수심이 한도에 도달하면 펌프가 멈춘 것처럼 유량 0. 운영비는 기존 정책에 따라 계속 부과되므로 UI 경고 필요.
6. **경제:** 파이프 길이당 설치비와 환불 정책을 GDD 승인 후 확정. 현재 임의 가격 적용 금지.
7. **저장:** 경로 타일을 체크포인트에 보관해야 재도전 시 시각적·물리적 일관성 유지. 기존 `pumpDischarges?` 필드 누락 시 외부 배출 유지.
8. **UX:** 모바일에서 연결 경로, 배출 포화, 전력 부족, 거리 초과를 서로 다른 메시지로 표시. 연결 취소·외부 배출 복귀 지원.

## 개발 순서
- D1: 경로 탐색 함수 + 결정적 테스트(직선/우회/차단/맵 경계).
- D2: 비용·유량·건설 규칙 승인.
- D3: 경로 미리보기·확정/취소 UI.
- D4: 저장·재도전·모바일 실기 회귀 검증.

## 출시 전 검증 기준
- 물량 보존 오차 허용치, 30TPS 성능, 파이프 경로 재현성, 이전 저장 호환성, 배포 SHA 일치.
- 테스트 성공과 실기 플레이 성공을 별도 기록.
