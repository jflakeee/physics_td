# Game Brief: Physics TD

**One-sentence pitch:** 막아낼수록 터전이 넓어지고 낯선 재해와 맞닿는다 — 신념이 다른 네 사람의 방식으로 홍수와 빙하를 다루는 모바일 웹 물리 디펜스.

## Core loop
- 준비: 물길·얼음 예보를 보고 구역·수문·스킬로 방어를 세운다
- 웨이브: 지형을 따라 흐르고 얼고 녹는 물을 보며 스킬로 대응한다
- 정산: 점수 → 경험치 → 레벨업 카드로 다른 캐릭터의 스킬을 섞는다
- 확장: 클리어하면 터전이 넓어지고, 새 지역과 기억 조각이 열린다

## Player goal & fail state — what "working" looks like
- 5웨이브 동안 기지 HP를 지키면 클리어하고 터전이 한 칸 넓어진다. 판마다 엔딩 1개와 점수가 남는다
- 기지 3×3 수위 합이 1.2를 넘은 만큼 HP가 줄고, 0이 되면 패배(웨이브 재도전)

## MVP — what must exist to be the game
1. 물·얼음 시뮬레이션 코어: 경사 분지, 월류, 제방 붕괴, 펌프, 강우 + 결빙·융해·빙하호 붕괴
2. 모바일 한 화면 UI + 구역 탭 조작(좌표 선택 없음)
3. 캐릭터 2명(둑지기·습지 연구원): 공통 스킬 2 + 특수 스킬 4씩, 빙하 지역용 스킬 표현 포함
4. 지역 2곳 × 맵 2장(강 유역·빙하시대), 5웨이브, 튜토리얼
5. 진영 확장 세계 지도(강 유역 → 빙하 경계 열림) + 서막 텍스트 + 기억 조각 8개
6. 판 안 레벨업 드래프트: 교차 스킬, 희귀도, 융합 1종(녹색 제방)
7. 결과 점수 + 엔딩 4종 + 도감 + 저장

## Out of scope — not building this
- 위험 계약·돌발 사건(출시 후 — MVP 7개 한도. 빙하 지역이 변주 역할을 대신함)
- 공병대장·수로 기술자, 융합 5종
- 화산 이후 지역(심해·산사태·외계·기계), 3~5막, 창조 모드
- 오늘의 유역, 뮤테이터, 숙련도 10단계, 비밀 엔딩, 명장면 리플레이
- 광고·에너지·결제, 멀티플레이, 서버, 줌/팬

## Build order
1. 물 시뮬레이션 코어 + 보정 결과 재현(방어 없음 W2 패배, 펌프 1대 단독 불가, 링+펌프 클리어)
2. 빙하호 붕괴 프로토타입: 얼음이 막고 녹으며 한꺼번에 쏟아지는 것이 위협이자 전략이 되는지 보정 — 가장 검증이 덜 된 부분
3. 모바일 한 화면 UI + 구역 탭 조작
4. 캐릭터 스킬(지역별 표현)
5. 맵 4장·튜토리얼
6. 레벨업 드래프트
7. 결과·엔딩·저장
8. 세계 지도·서막·기억 조각

---
**Who it's for / what they feel:** 5~7분 세션을 즐기는 모바일 물리·퍼즐 디펜스 팬. 물을 읽고 길을 열어 주는 쾌감, 낯선 땅과 맞닿는 발견의 설렘, 광고·과금 압박 없음.

**Art & audio direction:** 탑뷰 2D, 수심 그라데이션 물과 반투명 얼음, 빗소리·얼음 갈라지는 소리 = 위협 신호, 기지 수위 상승 시 저음 경고.

**Reference game:** Creeper World 4 — 지형을 따라 흐르는 유체를 다루는 핵심만 가져오고, 에너지망·공세 목표는 뺀다.
